# 7-7. 마우스로 다섯 자리 손글씨 숫자 인식하기

> 대상: 파이썬과 인공지능을 처음 배우는 학생  
> 안내: 설명은 **첨부된 원본 소스** 기준입니다. 코드를 수정하지 않고 설명합니다.

## 1. 이 프로그램은 무엇을 하나요?

창에 숫자 5개를 직접 그린 다음 앞서 학습한 AI가 무엇이라고 인식하는지 확인한다.

## 2. 동작 순서

1. 7-5에서 저장한 `dmlp_trained.h5`를 불러온다.
2. 흰색 캔버스와 빨간색 숫자 칸 5개를 만든다.
3. 마우스를 누른 채 움직여 숫자를 쓴다.
4. `r`을 누르면 다섯 숫자를 잘라 28×28로 변환한다.
5. AI가 예측한 숫자를 칸 아래에 표시하고 소리를 낸다.

## 3. 주요 코드 쉽게 이해하기

| 함수/코드 | 아주 쉬운 설명 |
|---|---|
| `load_model('dmlp_trained.h5')` | 저장해 둔 AI의 기억(학습된 가중치)을 불러옵니다. |
| `reset()` | 새하얀 그림판과 숫자 칸 다섯 개를 만듭니다. |
| `np.ones((200,520,3))*255` | 200×520 크기의 흰색 이미지 배열을 만듭니다. |
| `cv.rectangle(...)` | 글씨를 적을 빨간 테두리를 그립니다. |
| `writing(...)` | 마우스 왼쪽 버튼을 누르면 검은 점을 그립니다. |
| `cv.setMouseCallback(...)` | 마우스 동작을 `writing` 함수에 연결합니다. |
| `grab_numerals()` | 5칸을 각각 잘라 28×28 숫자 이미지로 만듭니다. |
| `255-cv.resize(...)` | 크기를 바꾼 뒤 흰 배경/검은 글씨를 **검은 배경/밝은 글씨**로 뒤집습니다. |
| `show()` | 전처리된 5개 숫자 그림을 보여 줍니다. |
| `reshape(5,784)` | 숫자 5개를 각각 784개 입력값으로 펼칩니다. |
| `model.predict(numerals)` | 5개 숫자 각각에 대한 예측 점수를 계산합니다. |
| `np.argmax(res,axis=1)` | 각 숫자의 10개 점수 중 가장 큰 값의 번호를 택합니다. |
| `winsound.Beep(1000,500)` | 윈도우에서 1000Hz 소리를 0.5초 냅니다. |

**키보드 조작:** `e` = 지우기, `s` = 모델이 보는 입력 미리보기, `r` = 인식, `q` = 종료.

**직접 숫자를 인식시키는 흐름:** `마우스로 그리기 → 칸 5개 잘라내기 → 28×28 축소 → 픽셀 반전 → 정규화 → AI 예측 → 숫자 표시`.

## 4. 실행하면 무엇이 나오나요?

`Writing` 창에 다섯 칸이 표시됩니다. 각 칸에 숫자를 쓰고 `r`을 누르면 아래에 예상 숫자가 나타납니다. `s`를 누르면 잘라낸 전처리 이미지를 별도 창에서 볼 수 있습니다.

## 5. 학생 실습 과제

- 첫 칸에 `3`을 굵게 써 보고 `r`을 누르세요.
- 같은 숫자를 작게/크게/기울여 쓰고 인식 결과를 비교하세요.
- `s`를 눌러 입력 이미지가 학습용 MNIST처럼 보이는지 살펴보세요.

## 6. 주의할 점과 자주 묻는 질문

- **7-5를 먼저 실행해 모델 파일을 만들어야 합니다.** `dmlp_trained.h5`를 실행 작업 디렉터리에서 찾지 못하면 실행 오류가 납니다.
- `winsound`는 Windows 전용입니다.
- 원본 코드에서는 영역을 고정 좌표로 잘라, 테두리/그림 위치가 결과에 영향을 줄 수 있습니다.
- 학습 데이터(MNIST)와 직접 쓴 숫자의 굵기·위치가 달라 틀릴 수 있습니다. 틀린 결과는 반드시 코드 오류를 뜻하지는 않습니다.
