# 7-5. MNIST 심층 신경망(DMLP)과 모델 저장

> 대상: 파이썬과 인공지능을 처음 배우는 학생  
> 안내: 설명은 **첨부된 원본 소스** 기준입니다. 코드를 수정하지 않고 설명합니다.

## 1. 이 프로그램은 무엇을 하나요?

은닉층을 3개로 늘리고 학습 결과를 파일로 저장해 다른 프로그램에서 재사용한다.

## 2. 동작 순서

1. MNIST 숫자 데이터를 불러와 전처리한다.
2. 784→1024→512→512→10 구조를 만든다.
3. ReLU, 교차엔트로피 손실, Adam을 사용해 학습한다.
4. 정확도를 출력하고 모델을 `dmlp_trained.h5`로 저장한다.
5. 학습/검증 정확도와 손실 그래프를 각각 그린다.

## 3. 주요 코드 쉽게 이해하기

| 코드 | 쉬운 설명 |
|---|---|
| `Dense(1024,activation='relu')` | 첫 번째 큰 은닉층입니다. |
| `Dense(512,activation='relu')` 두 줄 | 추가 은닉층 두 개로 더 많은 단계의 특징을 학습합니다. |
| `Dense(10,activation='softmax')` | 10개 숫자 중 어느 것이 가까운지 출력합니다. |
| `loss='categorical_crossentropy'` | 정답 숫자와 예측 확률의 차이를 분류에 맞게 계산합니다. |
| `Adam(learning_rate=0.0001)` | 작은 학습률로 가중치를 조정합니다. |
| `dmlp.save('dmlp_trained.h5')` | 학습한 모델을 파일로 저장합니다. |
| `hist.history['loss']` | 훈련 데이터의 손실 변화를 가져옵니다. |
| `hist.history['val_loss']` | 검증 데이터의 손실 변화를 가져옵니다. |

**DMLP란?** 은닉층이 여러 개인 다층 퍼셉트론입니다. 단순히 층이 많다고 항상 성능이 좋아지는 것은 아닙니다.

## 4. 실행하면 무엇이 나오나요?

콘솔에는 최종 정확도가 출력되고, 정확도 그래프와 손실 그래프가 순서대로 열립니다. 실행 작업 폴더에 `dmlp_trained.h5`가 만들어집니다. 이 파일은 7-7에서 사용합니다.

## 5. 학생 실습 과제

- 7-2보다 층이 몇 개 더 있는지 비교하세요.
- 검증 손실이 올라가는데 훈련 손실은 내려가는 구간이 있는지 찾으세요.
- 저장된 `.h5` 파일이 어디에 생겼는지 확인하세요.

## 6. 주의할 점과 자주 묻는 질문

- 원본은 `validation_data=(x_test,y_test)`를 사용합니다. 올바른 성능 비교에는 검증용/최종 테스트용 분리가 좋습니다.
- 경로가 상대경로이므로 파일은 소스 파일 위치가 아니라 **현재 작업 디렉터리**에 생성될 수 있습니다.

## 7. 한 줄 정리
