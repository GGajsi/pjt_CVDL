# IntelliJ IDEA에서 `9-5.py`에만 가상환경 지정하기

> **목표:** `pjt_CVDL` 프로젝트의 기본 Python 환경은 `.venv`로 유지하면서, PixelLib을 사용하는 `9-5.py`만 `.venv_cvbook`으로 실행합니다.  
> **개발 도구:** IntelliJ IDEA (Python 플러그인), Windows PowerShell  
> **범위:** 새 가상환경 설치가 아니라 **이미 생성된 가상환경의 등록 및 프로그램별 실행 설정**입니다.

## 1. 두 가상환경의 역할

| 환경 | Python | 주요 라이브러리 | 용도 |
|---|---|---|---|
| `.venv` | 3.11 | TensorFlow 2.21.0 | 기존 7~9장 프로그램 등의 기본 실습 |
| `.venv_cvbook` | 3.9 | TensorFlow 2.7.0, PixelLib 0.7.1 | `9-5.py` 전용 교재 실습 |

실제 Python 실행 파일 경로는 다음과 같습니다.

```text
기본 환경: K:\LSK\pjt_CVDL\.venv\Scripts\python.exe
교재 환경: K:\LSK\pjt_CVDL\.venv_cvbook\Scripts\python.exe
```

**주의:** Windows에 설치된 일반 Python 3.9(`C:\Users\pdd\AppData\Local\Programs\Python\Python39\python.exe`)와 `.venv_cvbook`의 Python 3.9는 서로 다른 실행 환경입니다. `9-5.py`에는 반드시 후자를 지정합니다.

## 2. IntelliJ에 기존 `.venv_cvbook` 등록

1. IntelliJ 메뉴에서 **File → Project Structure...**를 엽니다. (일반적으로 `Ctrl+Alt+Shift+S`)
2. 왼쪽의 **Platform Settings → SDKs**를 선택합니다.
3. SDK 목록 위 **`+`** 버튼을 클릭하여 **Add Python Interpreter** 창을 엽니다.
4. **Local**을 선택합니다.
5. `Environment`에서 **Generate new가 아니라 Select existing**을 선택합니다.
6. `Type`은 **Python**으로 유지합니다. (Conda·Poetry가 아닙니다.)
7. `Python path`에서 다음 실행 파일을 선택합니다.

   ```text
   K:\LSK\pjt_CVDL\.venv_cvbook\Scripts\python.exe
   ```

8. 창의 **OK**를 클릭합니다. 새 SDK가 목록에 나타나는지 확인합니다. 구별하기 쉬운 이름으로 `Python 3.9 (cvbook)`이라고 지정해도 됩니다.

> **자주 발생하는 실수:** `Generate new`를 선택하고 `Location`에 기존 `python.exe` 경로를 입력하면 “The specified folder already exists” 오류가 발생할 수 있습니다. 이미 설치한 환경이므로 **Select existing**이 맞습니다.

## 3. 프로젝트 기본 환경은 `.venv`로 유지

1. **Project Structure → Project**를 선택합니다.
2. `SDK`에서 기존 `.venv`를 가리키는 **Python 3.11 (pjt_CVDL)**을 선택합니다.
3. SDK의 실제 경로가 아래와 같은지 확인합니다.

   ```text
   K:\LSK\pjt_CVDL\.venv\Scripts\python.exe
   ```

4. **Apply → OK**를 누릅니다.

이렇게 하면 프로젝트 기본 SDK는 기존 환경을 유지합니다. 단, 특정 실행 구성이 명시한 인터프리터가 있으면 실행 시 그 지정이 우선합니다.

## 4. `9-5.py` 전용 Run Configuration 만들기

1. 메뉴 **Run → Edit Configurations...**를 엽니다.
2. 왼쪽 `Python` 아래에 `9-5_PixelLib` 구성이 있다면 선택합니다. 없다면 **`+` → Python**으로 새 실행 구성을 만듭니다.
3. 아래 값을 입력합니다.

| 항목 | 설정값 |
|---|---|
| **Name** | `9-5_PixelLib` |
| **Interpreter 사용 방식** | `Use specified interpreter` |
| **Python Interpreter** | `Python 3.9 virtualenv at ...\.venv_cvbook` |
| **Script** | `K:\LSK\pjt_CVDL\source\ch09\9-5.py` |
| **Working directory** | `K:\LSK\pjt_CVDL\source\ch09` |
| **Environment variables** | `PYTHONUNBUFFERED=1` (기존값 유지) |

4. **Apply → OK**를 누릅니다.
5. IntelliJ 상단 실행 구성 선택 메뉴에서 **`9-5_PixelLib`**을 고른 후 **초록색 실행(▶)** 버튼을 클릭합니다.

### Working directory가 중요한 이유

`9-5.py`는 모델과 입력 이미지를 상대 경로로 불러옵니다.

```python
seg.load_ade20k_model('deeplabv3_xception65_ade20k.h5')
img_fname = 'busy_street.jpg'
```

따라서 해당 파일이 놓인 `source\ch09`를 작업 디렉터리로 설정해야 상대 경로가 정확하게 해석됩니다.

## 5. 실행 환경이 올바른지 확인

IntelliJ의 **Run 창 첫 줄**에 다음 두 경로가 나타나는지 확인합니다.

```text
K:\LSK\pjt_CVDL\.venv_cvbook\Scripts\python.exe
K:\LSK\pjt_CVDL\source\ch09\9-5.py
```

추가로 `9-5.py` 맨 위에 임시로 아래 코드를 넣어 확인할 수 있습니다.

```python
import sys
print('사용 중인 Python:', sys.executable)
```

정상일 경우 `.venv_cvbook\Scripts\python.exe`가 출력됩니다. `PixelLib` import와 DeepLabV3+ 이미지 분할까지 실행되면 설정이 완료된 것입니다.

## 6. 프로그램별 실행 환경과 주의사항

| 프로그램 | 실행 환경 | 실행 방법 |
|---|---|---|
| `9-4.py` | 기존 `.venv` | 프로젝트 기본 환경 또는 별도 기존 실행 구성 확인 |
| `9-4_predict.py` | 기존 `.venv` | 프로젝트 기본 환경 또는 별도 기존 실행 구성 확인 |
| **`9-5.py`** | **`.venv_cvbook`** | **`9-5_PixelLib` 실행 구성 선택 후 실행** |

- IntelliJ 상단의 **Current File** 실행은 별도 임시 구성 또는 기존 구성에 따라 환경이 달라질 수 있습니다. `9-5.py`는 **명시적으로 `9-5_PixelLib`**을 선택하는 것이 안전합니다.
- PowerShell 터미널의 `(.venv_cvbook)` 표시와 IntelliJ의 **Run Configuration 인터프리터 설정은 별개**입니다.
- 가상환경 등록은 새 환경 설치가 아닙니다. 기존 `.venv` 및 `.venv_cvbook` 안의 패키지를 변경하지 않습니다.
- TensorFlow 2.7.0에서 GPU DLL 경고가 나타나더라도, CPU 실행을 선택한 현재 실습에서는 GPU 설치가 필수는 아닙니다.

## 7. 터미널에서 직접 실행하는 대체 방법

별도의 Run Configuration 없이 **Python 실행 파일을 명시**해서 실행할 수도 있습니다.

```powershell
cd K:\LSK\pjt_CVDL\source\ch09
& "K:\LSK\pjt_CVDL\.venv_cvbook\Scripts\python.exe" .\9-5.py
```

이 방식은 터미널에 어떤 가상환경이 활성화되어 있든 `.venv_cvbook`을 직접 사용합니다.

## 8. 최종 점검표

- [ ] `.venv_cvbook\Scripts\python.exe`를 기존 인터프리터로 등록했다.
- [ ] Project SDK는 기존 `.venv`(Python 3.11)를 유지한다.
- [ ] `9-5_PixelLib`에서 **Use specified interpreter**를 선택했다.
- [ ] Script가 `source\ch09\9-5.py`를 가리킨다.
- [ ] Working directory가 `source\ch09`이다.
- [ ] Run 창에서 `.venv_cvbook\Scripts\python.exe`를 확인했다.
- [ ] 원본 이미지, 분할 이미지, 오버레이 이미지가 정상 출력된다.

---

**최종 원칙:** 프로젝트의 기본 환경은 `.venv`, `9-5.py`의 전용 실행 환경은 `.venv_cvbook`입니다. IDE에 두 환경을 등록하고 **Run Configuration별로 실행 파일과 인터프리터를 지정**하면 프로그램마다 환경을 안전하게 분리할 수 있습니다.
