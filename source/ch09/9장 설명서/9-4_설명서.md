## 5. 핵심 코드 단계별 설명

### 1단계. 파일 위치와 분할 클래스

```python
input_dir='./datasets/oxford_pets/images/images/'
target_dir='./datasets/oxford_pets/annotations/annotations/trimaps/'
img_siz=(160,160)
n_class=3
```

원본 경로가 두 번 중첩되어 있으므로 실제 압축 해제 위치와 반드시 비교해야 합니다. 3개 클래스는 물체/배경/경계입니다.

### 2단계. 정답 마스크 숫자 바꾸기

```python
y[j]=np.expand_dims(img,2)
y[j]-=1
```

원래 1·2·3 값을 모델 학습용 0·1·2로 바꿉니다.

### 3단계. 축소와 확대

```python
x=layers.SeparableConv2D(filters,3,padding='same')(x)
x=layers.UpSampling2D(2)(x)
x=layers.add([x,residual])
```

축소 과정은 특징을 찾고, 확대 과정은 각 픽셀이 어느 클래스인지 되살립니다. 지름길 연결은 중간 정보를 더해줍니다.

### 4단계. 학습과 저장

```python
model.compile(optimizer='adam',loss='sparse_categorical_crossentropy',metrics=['accuracy'])
cb=[keras.callbacks.ModelCheckpoint('oxford_seg.h5',save_best_only=True)]
model.fit(train_gen,epochs=30,validation_data=test_gen,callbacks=cb)
```

분할 정답은 원-핫이 아니라 정수 레이블이므로 sparse categorical crossentropy를 사용합니다.

분할 출력의 각 픽셀은 세 종류에 대한 점수 벡터입니다. 각 위치에서 가장 큰 점수의 **인덱스**를 선택하면 픽셀별 예측 클래스(0, 1, 2)를 얻습니다.

```python
predicted_mask = np.argmax(preds[0], axis=-1)
```

## 8. 실행 준비와 주의 사항

- 원본의 마스크 `load_img(...,color_mode="grayscale")`는 기본 보간이 적용됩니다. 레이블 마스크는 `interpolation="nearest"`를 쓰는 편이 안전합니다.
- `preds[0]`은 대개 (160,160,3) 클래스 점수입니다. 바로 `imshow`하기보다 `np.argmax(preds[0],axis=-1)`로 클래스 지도를 만든 뒤 표시해야 정확히 이해할 수 있습니다.
- 원본은 10%를 `test`라 불러 매 에포크 검증합니다. 엄밀히는 검증 집합이며 최종 평가용 테스트 집합은 별도로 두는 것이 좋습니다.
- Keras 버전에 따라 `keras.utils.Sequence` 구현과 체크포인트 확장자 관련 호환성 문제가 생길 수 있습니다.

**최신 보충 내용(실행 환경 참고):** TensorFlow/Keras·PixelLib·OpenCV 버전이 교재 작성 당시와 다를 수 있습니다. 원본 예제와 현재 라이브러리의 호환성을 별도로 확인해야 합니다. 본 설명서는 실제 실행 성공 여부를 확인했다고 주장하지 않습니다.
