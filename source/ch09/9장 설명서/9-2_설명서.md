4. `q` 키를 누르면 반복을 종료합니다.

## 5. 핵심 코드 단계별 설명

### 1단계. 카메라 열기

```python
cap=cv.VideoCapture(0,cv.CAP_DSHOW)
if not cap.isOpened(): sys.exit('카메라 연결 실패')
```

`0`은 기본 카메라입니다. `CAP_DSHOW`는 Windows의 DirectShow 백엔드입니다.

### 2단계. 프레임 읽기

```python
while True:
    ret,frame=cap.read()
    if not ret: sys.exit('프레임 획득에 실패하여 루프를 나갑니다.')
```

`ret`은 프레임 읽기 성공 여부, `frame`은 현재 카메라 사진입니다.

### 3단계. 프레임 검출

```python
res=yolo_detect(frame,model,out_layers)
cv.imshow('Object detection from video by YOLO v.3',frame)
```

매 프레임 같은 모델로 추론하고 결과를 실시간 창에 보여줍니다.

### 4단계. 종료 처리

```python
key=cv.waitKey(1)
if key==ord('q'): break
cap.release()
cv.destroyAllWindows()
```

`q`를 누르면 카메라 자원을 반환하고 창을 닫습니다.

## 7. 핵심 수식 또는 계산

물체 위치는 중심 좌표와 너비·높이를 사각형의 좌상단·우하단 좌표로 바꾸어 표시합니다.

- `centerx`, `centery`: 사각형 중심의 가로·세로 좌표
- `w`, `h`: 사각형 너비·높이
- `x1 = centerx - w/2`, `y1 = centery - h/2`
- `x2 = x1 + w`, `y2 = y1 + h`

## 8. 실행 준비와 주의 사항

- 카메라 앱이나 다른 프로그램이 카메라를 사용 중이면 열기 실패가 발생할 수 있습니다.
- CPU로 YOLOv3를 실행하면 화면 갱신이 느릴 수 있습니다.
- 프레임 읽기 오류에서 `sys.exit()`로 종료되면 `cap.release()`가 실행되지 않을 수 있어 `try/finally` 구조가 더 안전합니다.

**최신 보충 내용(실행 환경 참고):** TensorFlow/Keras·PixelLib·OpenCV 버전이 교재 작성 당시와 다를 수 있습니다. 원본 예제와 현재 라이브러리의 호환성을 별도로 확인해야 합니다. 본 설명서는 실제 실행 성공 여부를 확인했다고 주장하지 않습니다.
