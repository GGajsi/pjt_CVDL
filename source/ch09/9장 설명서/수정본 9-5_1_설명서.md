# 9-5_1.py 프로그램 설명서 — 사진의 의미 분할(SegFormer)

- **기준 소스:** `9-5_1.py` (첨부된 수정본)
- **교재 연결:** 『컴퓨터 비전과 딥러닝』 9장 인식, 프로그램 9-5(의미 분할 실습, 411쪽 부근)
- **교재와 달라진 점:** PixelLib + DeepLabv3 대신 **Hugging Face의 SegFormer-B0**를 사용합니다. 이 부분은 **최신 보충 내용**입니다.

## 1. 선수 지식 확인

이미지의 픽셀, OpenCV의 BGR/RGB 순서, `numpy` 배열과 `cv.imshow()`를 알고 있으면 좋습니다.

## 2. 오늘의 학습 목표

1. 의미 분할과 물체 검출의 차이를 설명합니다.
2. SegFormer 모델을 불러와 사진 전체의 픽셀을 분류합니다.
3. 원본·마스크·합성 영상을 비교합니다.

## 3. 핵심 개념 — 일상적인 비유

물체 검출이 사진 위에 **'여기에 자동차가 있어요'라는 네모 상자**를 그리는 작업이라면, 의미 분할은 **색칠 공부처럼 사진의 각 픽셀에 '도로', '자동차', '하늘' 등 이름표**를 붙이는 작업입니다. 같은 종류의 여러 물체는 동일한 분류 색상으로 표시될 수 있습니다.

**처리 흐름**

```text
busy_street.jpg 확인
  → OpenCV(BGR)와 PIL(RGB)로 읽기
  → SegFormer 전처리 → AI 모델 추론
  → 저해상도 출력(logits)을 원본 크기로 확대
  → 픽셀별 최대 점수 클래스(argmax) 선택
  → 150개 색상 중 하나로 칠하기
  → 원본 / 컬러 마스크 / 합성 영상 표시
```

## 4. 핵심 코드 단계별 해설

### ① 이미지 경로 지정

```python
BASE_DIR = Path(__file__).resolve().parent
IMAGE_PATH = BASE_DIR / 'busy_street.jpg'
```

`__file__`은 현재 소스 파일의 위치입니다. 따라서 실행 작업 폴더가 바뀌어도 `9-5_1.py`와 같은 폴더에 있는 이미지를 찾습니다. 파일이 없으면 `FileNotFoundError`로 즉시 알려줍니다.

### ② 사전 학습 모델 읽기

```python
model_id = 'nvidia/segformer-b0-finetuned-ade-512-512'
processor = SegformerImageProcessor.from_pretrained(model_id)
model = SegformerForSemanticSegmentation.from_pretrained(model_id)
```

`processor`는 모델에 맞는 이미지 입력을 만들어 주고, `model`은 각 픽셀의 분류 점수를 계산합니다. 최초 실행에서는 인터넷을 통해 모델을 내려받을 수 있습니다. **이 소스는 학습이 아닌 추론**을 수행합니다.

### ③ 추론할 때 기울기 계산 생략

```python
inputs = processor(images=img_pil, return_tensors='pt')
with torch.no_grad():
    outputs = model(**inputs)
```

`torch.no_grad()`는 예측만 할 때 학습용 기울기를 계산하지 않아 메모리 사용을 줄입니다.

### ④ 예측 마스크를 원본 크기로 복구

```python
logits = outputs.logits
logits = F.interpolate(logits, size=img_pil.size[::-1],
                       mode='bilinear', align_corners=False)
predicted_mask = logits.argmax(dim=1).squeeze().cpu().numpy()
```

- `logits`: 각 분류에 대한 점수 묶음(아직 확률이 아닐 수 있음)
- `img_pil.size`: `(가로, 세로)`이므로 `[::-1]`로 `(세로, 가로)`로 바꿉니다.
- `argmax(dim=1)`: 픽셀마다 점수가 가장 높은 클래스의 **번호**를 고릅니다.
- `.cpu().numpy()`: NumPy로 사용할 배열을 만듭니다.

### ⑤ 마스크와 원본 영상 합치기

```python
np.random.seed(42)
palette = np.random.randint(0, 255, (150, 3), dtype=np.uint8)
color_mask = palette[predicted_mask]
color_mask_bgr = cv.cvtColor(color_mask, cv.COLOR_RGB2BGR)
img_overlay = cv.addWeighted(img_cv, 0.6, color_mask_bgr, 0.4, 0)
```

색상표의 각 색은 **분류 번호를 구별하기 위한 임의 색**이며 실제 도로·사람의 색을 뜻하지 않습니다. `seed(42)`는 실행할 때마다 같은 팔레트를 사용하게 합니다.

**합성 공식:** `결과 = 0.6 × 원본 + 0.4 × 마스크 + 0`. 두 가중치 0.6과 0.4는 각 영상이 화면에서 차지하는 비중입니다.

## 5. 간단한 실습 및 실행 방법

1. `9-5_1.py` 옆에 `busy_street.jpg`를 둡니다.
2. 필요한 환경에서 `pip install transformers torch pillow opencv-python`을 실행합니다.
3. 프로그램을 실행하면 `Original`, `Semantic Mask`, `Overlayed` 창 3개가 나타납니다.
4. `cv.waitKey(0)`으로 대기하다가 이미지 창에서 키를 누르면 종료합니다.

## 6. 자주 발생하는 오류

| 증상 | 원인 및 확인 | 수정 방법 |
|---|---|---|
| 이미지 파일 없음 | `IMAGE_PATH`가 실제 사진을 가리키는지 확인 | 사진을 소스와 같은 폴더에 배치 |
| `ModuleNotFoundError` | 설치한 패키지가 실행 중 가상환경과 다름 | 현재 `.venv` 터미널에서 설치 |
| 모델 다운로드 실패 | 첫 실행에 네트워크 연결 필요 | 인터넷과 Hugging Face 접근 확인 |
| 색상 이상 | RGB/BGR 혼동 | `cv.COLOR_RGB2BGR` 유지 |


## 확인 문제 3개 (정답 대신 힌트)

1. 의미 분할은 바운딩 박스 대신 무엇을 분류하나요? **힌트:** 이미지의 가장 작은 단위입니다.
2. `argmax(dim=1)`의 역할은 무엇일까요? **힌트:** 한 픽셀의 클래스 점수가 여러 개 있습니다.
3. `0.6`과 `0.4`를 바꾸면 무엇이 달라질까요? **힌트:** 원본과 색칠한 마스크 중 무엇이 더 선명해질까요?
