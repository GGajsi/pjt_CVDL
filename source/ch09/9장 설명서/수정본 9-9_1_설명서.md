# 9-9_1.py 프로그램 설명서 — YOLOv8 + PyQt5 실시간 배경 효과

- **기준 소스:** `9-9_1.py` (첨부된 수정본)
- **교재 연결:** 9장 프로그램 9-9(비전 에이전트: 배경을 내 맘대로, 417쪽 부근)
- **최신 보충 내용:** PixelLib의 `alter_bg` 대신 **YOLOv8n-seg**를 활용하고, 카메라 반복 처리를 `QTimer`에 연결했습니다.

## 1. 선수 지식 확인

PyQt5의 버튼과 콤보박스, OpenCV의 BGR 색상, 영상 마스크, `GaussianBlur`를 이해하고 시작합니다.

## 2. 오늘의 학습 목표

1. GUI에서 버튼과 콤보박스로 영상 효과를 제어합니다.
2. YOLO로 사람과 배경을 나누는 마스크를 만듭니다.
3. 사람은 그대로 유지하며 배경을 흐리게 하거나 색을 바꿉니다.

## 3. 쉬운 비유와 전체 처리 흐름

사람을 종이에서 오려 붙인다고 생각해 보세요. 사람을 덮는 **오려낸 종이(마스크)**를 유지하고, 그 뒤에 있는 배경만 흐리게 만들거나 색종이로 바꾸는 방식입니다.

```text
GUI 창 만들기 → YOLOv8n-seg 모델 로딩
   ↓ [배경 내 맘대로 켜기] 클릭
웹캠 열기 → QTimer 시작 → 프레임 읽기
   ↓
콤보박스 선택이 '원래 영상'이면 그대로 출력
   ↓ (그 외 효과)
YOLO로 사람 마스크 추출 → 배경 이미지 만들기
   ↓
사람 영역은 원본 + 나머지는 바뀐 배경
   ↓
OpenCV 창에 표시 → 타이머 반복
   ↓ [나가기] 클릭
타이머 정지 → 카메라 해제 → 창 닫기
```

## 4. 단계별 핵심 코드 설명

### ① YOLO 모델을 시작할 때 로딩

```python
from ultralytics import YOLO
self.model = YOLO('yolov8n-seg.pt')
```

`n`(Nano) 모델은 가벼운 편입니다. 모델은 영상의 사람 영역을 예측합니다. 최초 실행 시 가중치 다운로드가 필요할 수 있습니다.

### ② 버튼·콤보박스·이벤트 연결

```python
self.pickCombo.addItems([
    '원래 영상', '흐릿(조금)', '흐릿(중간)', '흐릿(많이)',
    '빨강', '녹색', '파랑'
])
videoButton.clicked.connect(self.start_video)
```

버튼을 누르면 `start_video()`를 호출하고, 콤보박스는 사용할 효과의 번호(`currentIndex()`)를 제공합니다.

### ③ QTimer로 프레임 처리 요청

```python
self.timer = QTimer(self)
self.timer.timeout.connect(self.update_frame)
self.timer.start(33)
```

33밀리초마다 `update_frame` 실행을 요청하는 구조입니다. `while True`로 UI 이벤트를 막지 않는 장점이 있지만, **추론이 33ms보다 오래 걸리면 실제 30FPS를 달성하지 못하고 GUI가 일시적으로 멈출 수도 있습니다.** 무거운 추론을 완전히 분리하려면 작업 스레드가 추가로 필요합니다.

### ④ 사람만 선택해 마스크 생성

```python
results = self.model.predict(source=frame, classes=[0], conf=0.5, verbose=False)
mask = np.zeros(frame.shape[:2], dtype=np.uint8)
if results[0].masks is not None:
    for poly in results[0].masks.xy:
        cv.fillPoly(mask, [poly.astype(np.int32)], 255)
```

`classes=[0]`은 사람만 선택합니다. `mask`는 처음에는 모두 0(배경)이고, `fillPoly()`를 통해 사람 영역을 255로 채웁니다. 여러 사람이 있다면 해당 다각형을 순서대로 칠합니다.

### ⑤ 배경을 흐리게 만들기

```python
k = {1: 15, 2: 31, 3: 51}[pick_effect]
bg = cv.GaussianBlur(frame, (k, k), 0)
special_img = np.where(mask[:, :, np.newaxis] == 255, frame, bg)
```

- 커널 크기 `15`, `31`, `51`은 흐림 강도에 사용됩니다.
- `np.newaxis`는 `(높이, 너비)` 마스크를 컬러 영상과 함께 쓰기 위해 차원을 늘립니다.
- `np.where(조건, A, B)`는 조건이 참이면 `A(사람 원본)`, 거짓이면 `B(바뀐 배경)`를 선택합니다.

**합성 규칙**: `최종 픽셀 = 원본 픽셀(마스크=255) / 배경 픽셀(마스크=0)`입니다. 색 값은 OpenCV의 **BGR** 순서를 사용합니다.

### ⑥ 배경을 단색으로 바꾸기

```python
if pick_effect == 4: bg[:] = (0, 0, 255)  # 빨강
elif pick_effect == 5: bg[:] = (0, 255, 0)  # 녹색
elif pick_effect == 6: bg[:] = (255, 0, 0)  # 파랑
```

마스크가 0인 배경을 빨강·녹색·파랑으로 바꾸고, 사람 영역은 원래 색으로 유지합니다.

### ⑦ 종료 처리

```python
self.timer.stop()
if self.cap is not None:
    self.cap.release()
cv.destroyAllWindows()
self.close()
```

타이머를 멈춘 후 카메라 자원을 반납해야 다른 프로그램에서도 웹캠을 사용할 수 있습니다.

## 5. 간단한 실행 실습

1. `pip install ultralytics opencv-python PyQt5 numpy`로 준비합니다.
2. 프로그램 실행 후 **배경 내 맘대로 켜기**를 클릭합니다.
3. 콤보박스에서 흐릿(조금) → 흐릿(많이) → 빨강을 차례대로 고릅니다.
4. 몸을 움직일 때 사람의 윤곽이 잘 유지되는지 관찰합니다.
5. **나가기**로 종료합니다.

## 6. 코드 검토 시 주의할 점

| 현상 | 원인·확인 | 해결 방향 |
|---|---|---|
| 모델 초기화가 오래 걸림 | 첫 다운로드 또는 모델 로딩 | 잠시 대기·인터넷 점검 |
| 화면이 느리거나 버튼 반응이 늦음 | QTimer 슬롯 안에서 추론 실행 | 작은 모델 사용, 처리 프레임 간격 늘리기, 필요하면 QThread 적용 |
| 사람이 화면에서 사라짐 | 사람 탐지 실패로 마스크가 모두 0 | 조명 개선·`conf` 조절; 사람 전체가 배경으로 처리될 수 있음 |
| 종료 후 카메라 사용 불가 | 카메라 자원이 남아 있음 | `quitFunction()`을 통한 종료 확인 |
| 빨강/파랑이 뒤바뀜 | OpenCV는 RGB가 아닌 BGR | `(0,0,255)`가 빨강임을 확인 |


## 확인 문제 3개 (정답 대신 힌트)

1. QTimer는 왜 사용하는 걸까요? **힌트:** GUI의 버튼 클릭 이벤트도 동시에 처리해야 합니다.
2. 사람의 마스크 값이 255인 곳에는 원본과 배경 중 무엇이 표시되나요? **힌트:** `np.where`의 참일 때 값을 보세요.
3. `cv.GaussianBlur`의 커널 15와 51 중 일반적으로 더 흐릿한 것은 어느 쪽인가요? **힌트:** 주변을 더 넓게 평균내는 쪽입니다.
