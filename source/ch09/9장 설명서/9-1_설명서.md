## 5. 핵심 코드 단계별 설명

### 1단계. 모델과 클래스 이름 준비

```python
f=open('coco_names.txt', 'r')
class_names=[line.strip() for line in f.readlines()]
model=cv.dnn.readNet('yolov3.weights','yolov3.cfg')
```

`coco_names.txt`에는 인식 대상 이름, `.cfg`에는 모델 구조, `.weights`에는 학습된 가중치가 들어 있습니다.

### 2단계. 입력 이미지 준비

```python
img=cv.imread('soccer.jpg')
test_img=cv.dnn.blobFromImage(img,1.0/256,(448,448),(0,0,0),swapRB=True)
```

`blobFromImage`는 이미지 크기·화소값·색상 채널을 신경망이 받아들일 형태로 바꿉니다.

### 3단계. 예측과 후보 정리

```python
yolo_model.setInput(test_img)
output3=yolo_model.forward(out_layers)
ind=cv.dnn.NMSBoxes(box,conf,0.5,0.4)
```

`forward()`로 예측합니다. NMS는 중복 사각형을 제거합니다. `box`와 `conf`는 그 앞 반복문에서 채운 목록입니다.

### 4단계. 결과 시각화

```python
cv.rectangle(img,(x1,y1),(x2,y2),colors[id],2)
cv.putText(img,text,(x1,y1+30),cv.FONT_HERSHEY_PLAIN,1.5,colors[id],2)
```

화면에 물체 위치와 클래스·예측 점수를 적습니다.

- **NMS:** 겹치는 후보 상자를 줄이는 과정

## 7. 핵심 수식 또는 계산

물체 위치는 중심 좌표와 너비·높이를 사각형의 좌상단·우하단 좌표로 바꾸어 표시합니다.

- `centerx`, `centery`: 사각형 중심의 가로·세로 좌표
- `w`, `h`: 사각형 너비·높이
- `x1 = centerx - w/2`, `y1 = centery - h/2`
- `x2 = x1 + w`, `y2 = y1 + h`

## 8. 실행 준비와 주의 사항

- `yolov3.weights`, `yolov3.cfg`, `coco_names.txt`, `soccer.jpg`가 현재 작업 폴더에 있어야 합니다.
- 원본 구현은 `vec85[5:]`의 최대 점수를 신뢰도로 사용합니다. 일반적으로 물체 존재 점수(objectness)까지 고려할 수도 있습니다.
- `getUnconnectedOutLayers()`의 반환 형태가 OpenCV 버전마다 다를 수 있습니다.

**최신 보충 내용(실행 환경 참고):** TensorFlow/Keras·PixelLib·OpenCV 버전이 교재 작성 당시와 다를 수 있습니다. 원본 예제와 현재 라이브러리의 호환성을 별도로 확인해야 합니다. 본 설명서는 실제 실행 성공 여부를 확인했다고 주장하지 않습니다.
