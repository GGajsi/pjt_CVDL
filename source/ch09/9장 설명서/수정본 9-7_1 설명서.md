# 9-7_1.py 프로그램 설명서

> **학습 주제:** YOLOv8 인스턴스 분할을 이용한 5가지 결과 시각화  
> **기준 소스:** 첨부된 `9-7_1.py` (원본 소스는 수정하지 않음)  
> **교재 연결:** 『컴퓨터 비전과 딥러닝』 9장 인식, **9-7 「정지 영상을 사례 분할하기」 약 414쪽**.  
> **최신 보충 내용:** 교재의 PixelLib/Mask R-CNN 대신 Ultralytics **YOLOv8s-seg**를 사용하는 수정 실습입니다.

## 1. 선수 지식 확인

학습 전에 다음을 알고 있으면 좋습니다.

- **OpenCV**: `cv.imread()`로 사진을 열고 `cv.imshow()`로 보여 주는 방법
- **NumPy 배열**: `img[y1:y2, x1:x2]`로 영상 일부분 잘라 내기
- **분류와 검출**: 사진에 무엇이 있는지 구별하는 것과 위치까지 찾는 것의 차이
- **마스크**: 픽셀마다 ‘선택한 부분인지’를 표시하는 흑백 도안

## 2. 오늘의 학습 목표

1. 인스턴스 분할이 물체의 종류·위치·모양을 함께 구한다는 사실을 설명할 수 있다.
2. `YOLO('yolov8s-seg.pt')`와 `model.predict()`의 역할을 말할 수 있다.
3. **원본 / 기본 분할 / 포커스 / 블러 / 자동차 크롭**의 5가지 결과를 구분할 수 있다.
4. 클래스 이름에 따라 사람·자전거·가방·자동차를 다르게 처리할 수 있다.
5. 잘라 낸 자동차 사진의 저장 위치를 확인할 수 있다.

## 3. 핵심 개념 — 생활 속 비유부터

사진에 사람이 세 명, 자전거가 한 대 있다고 생각해 봅시다.

- **이미지 분류**는 “이 사진에는 사람이 있다”라고 말하는 것입니다.
- **객체 검출**은 “사람은 여기, 자전거는 저기”라며 **네모 상자**를 그리는 것입니다.
- **인스턴스 분할**은 사람마다 **정확한 몸 윤곽을 색칠**하는 것입니다. 사람이 세 명이면 각각의 윤곽을 따로 얻습니다.

이 프로그램은 이렇게 얻은 물체 윤곽을 활용해 다양한 사진 편집 효과를 한 번에 보여 줍니다.

### 전체 처리 흐름

```text
busy_street.jpg 읽기
       ↓
YOLOv8s-seg 모델 불러오기
       ↓
물체 검출 + 인스턴스 분할 (클래스·박스·윤곽)
       ↓
┌──────────────────────┬───────────────────────┬───────────────────────┐
│ 사람·자전거 마스크   │ 사람·가방 마스크      │ 자동차 바운딩 박스   │
│ 배경 흑백/대상 컬러  │ 대상만 흐리게 처리   │ 자동차 사진 잘라내기 │
└──────────────────────┴───────────────────────┴───────────────────────┘
       ↓
결과 5개 창 출력 + 자동차 파일 저장 + 객체 개수 출력
```

## 5. 코드 단계별 설명

### ① 필요한 도구 불러오기 (6~10줄)

```python
from ultralytics import YOLO
from collections import Counter
from pathlib import Path
import cv2 as cv
import numpy as np
```

| 도구 | 쉬운 역할 |
|---|---|
| `YOLO` | 사진에서 물체를 찾아 윤곽을 얻는 AI |
| `Counter` | 물체별로 몇 개 찾았는지 세는 계산기 |
| `Path` | 파일 위치를 안전하게 관리하는 도구 |
| `cv2` | 사진 읽기·그리기·블러·출력·저장 |
| `numpy` | 이미지 배열과 마스크 처리 |

### ② 사진 경로 및 저장 폴더 준비 (12~23줄)

```python
BASE_DIR = Path(__file__).resolve().parent
IMAGE_PATH = BASE_DIR / 'busy_street.jpg'
CARS_DIR = BASE_DIR / 'cars'
CARS_DIR.mkdir(parents=True, exist_ok=True)
```

- `IMAGE_PATH`: 분석할 사진을 지정합니다.
- `CARS_DIR`: 찾아낸 자동차 사진을 저장할 폴더입니다.
- `mkdir(..., exist_ok=True)`: 폴더가 없어도 만들고, 이미 있어도 오류를 내지 않습니다.
- 파일이 없으면 `FileNotFoundError`로 어떤 사진이 빠졌는지 알려 줍니다.

### ③ YOLOv8 분할 모델과 추론 (25~35줄)

```python
model = YOLO('yolov8s-seg.pt')
results = model.predict(source=img_original, conf=0.3, save=False)
result = results[0]
img_standard_seg = result.plot()
```

- `yolov8s-seg.pt`: 객체의 윤곽까지 검출할 수 있는 **사전 학습된 Small 모델**입니다.
- `source=img_original`: 읽어 둔 사진을 AI에 입력합니다.
- `conf=0.3`: 예측 신뢰도 **0.3 이상**인 후보를 사용하도록 설정합니다. 점수는 정답일 확률이 보장된 수치가 아닙니다.
- `save=False`: Ultralytics의 기본 결과 자동 저장을 끕니다. 뒤에서 수행하는 자동차 저장은 별개의 동작입니다.
- `results[0]`: 입력 사진 한 장의 결과입니다.
- `result.plot()`: 기본 컬러 분할·바운딩 박스가 표시된 이미지를 만듭니다.

### ④ 흑백 화면과 흐린 화면 만들기 (37~45줄)

```python
gray = cv.cvtColor(img_original, cv.COLOR_BGR2GRAY)
gray_bgr = cv.cvtColor(gray, cv.COLOR_GRAY2BGR)
img_blurred = cv.GaussianBlur(img_original, (51, 51), 0)
mask_focus = np.zeros(img_original.shape[:2], dtype=np.uint8)
mask_blur = np.zeros(img_original.shape[:2], dtype=np.uint8)
```

- `gray_bgr`: 흑백 사진을 3채널로 바꿔 원본 컬러 영상과 합성하기 쉽게 합니다.
- `GaussianBlur(..., (51, 51), 0)`: 주변 픽셀을 섞어 사진 전체를 흐리게 만듭니다.
- `mask_focus`, `mask_blur`: 처음에는 픽셀 값이 모두 **0(선택되지 않음)**인 흑백 마스크입니다.

### ⑤ 인식한 물체를 하나씩 확인하기 (50~60줄)

```python
boxes = result.boxes
masks = result.masks.xy

for i in range(len(boxes)):
    cls_id = int(boxes.cls[i].item())
    class_name = model.names[cls_id]
    polygon = masks[i].astype(np.int32)
```

- `boxes.cls[i]`: i번째 물체의 **클래스 번호**입니다.
- `model.names[cls_id]`: 번호를 `person`, `car` 같은 이름으로 바꿉니다.
- `masks[i]`: 해당 물체의 윤곽을 이루는 점 좌표 목록입니다.
- `polygon`: OpenCV가 다각형을 색칠하도록 정수 좌표로 변환한 것입니다.

코드는 `boxes`와 `masks`가 모두 있을 때만 이 반복문을 실행합니다. 아무 물체도 검출하지 못해도 프로그램이 결과 화면을 만들도록 구성되어 있습니다.

### ⑥ 사람과 자전거를 컬러로 강조하기 (62~64, 87~89줄)

```python
if class_name in ['person', 'bicycle']:
    cv.fillPoly(mask_focus, [polygon], 255)

img_focus = gray_bgr.copy()
img_focus[mask_focus == 255] = img_original[mask_focus == 255]
```

- `fillPoly(...)`는 선택한 객체 윤곽 **내부를 흰색(255)**으로 칠합니다.
- 마스크가 255인 픽셀만 원본 컬러를 가져오고, **나머지는 흑백**으로 둡니다.
- 마치 포스터에서 사람과 자전거만 색연필로 강조하는 효과입니다.

### ⑦ 사람과 가방만 흐리게 처리하기 (66~68, 91~93줄)

```python
if class_name in ['person', 'backpack', 'handbag']:
    cv.fillPoly(mask_blur, [polygon], 255)

img_blur_only = img_original.copy()
img_blur_only[mask_blur == 255] = img_blurred[mask_blur == 255]
```

- 사람, 배낭, 핸드백으로 인식된 부분만 흐리게 처리합니다.
- 배경은 원본 컬러 그대로 둡니다.
- 코드 주석은 프라이버시 보호라고 설명하지만, **실제 비식별화를 보장하는 기능은 아닙니다.** 얼굴 등이 충분히 가려졌는지 별도 검증해야 합니다.

### ⑧ 자동차 사진을 자동으로 잘라 저장하기 (70~84줄)

```python
if class_name == 'car':
    x1, y1, x2, y2 = boxes.xyxy[i].cpu().numpy().astype(int)
    car_crop = img_original[y1:y2, x1:x2]
    crop_path = CARS_DIR / f'car_{car_count}.jpg'
    cv.imwrite(str(crop_path), car_crop)
    car_count += 1
```

- `(x1, y1)`은 상자 왼쪽 위, `(x2, y2)`는 오른쪽 아래 좌표입니다.
- `img_original[y1:y2, x1:x2]`로 자동차가 있는 **직사각형 영역**을 잘라 냅니다.
- 이는 **윤곽에 딱 맞춘 투명 배경 추출이 아니라 바운딩 박스 크롭**입니다. 상자 안의 주변 배경도 함께 들어갈 수 있습니다.
- 자동차가 여러 개면 `car_1.jpg`, `car_2.jpg`처럼 번호를 붙여 저장합니다.
- 다음 코드에서 높이를 250픽셀로 맞춘 후 콜라주용 리스트에 담습니다.

```python
h, w = car_crop.shape[:2]
ratio = 250 / h
resized_crop = cv.resize(car_crop, (int(w * ratio), 250))
car_crops.append(resized_crop)
```

이 부분은 `h`가 0이거나 `int(w * ratio)`가 0이면 오류가 날 수 있습니다. 작은·잘못된 박스에 대비하려면 아래의 개선 예시를 참고하세요.

### ⑨ 자동차 콜라주와 개수 출력 (95~111줄)

```python
if car_crops:
    img_cropped_cars = cv.hconcat(car_crops)
else:
    img_cropped_cars = np.zeros((250, 500, 3), dtype=np.uint8)

object_counts = Counter(detected_classes)
```

- `cv.hconcat(...)`: 높이를 통일한 자동차 사진을 **가로로 연결**합니다.
- 자동차가 한 대도 없으면 ‘No cars detected’라는 빈 화면을 만듭니다.
- `Counter`로 검출한 객체를 종류별로 세어 터미널에 출력합니다. 실제 개수와 검출 개수는 다를 수 있습니다.

for title, img in window_configs:

`WINDOW_NORMAL`을 사용하므로 창 크기를 조절할 수 있습니다. 이미지 창이 활성화된 상태에서 키를 누르면 프로그램이 종료됩니다.

## 8. 오류가 발생하면: 원인 → 확인 → 수정

### 오류 1: `busy_street.jpg`를 찾을 수 없음

**원인:** 소스 파일 옆에 사진이 없습니다.  
**확인:** `print(IMAGE_PATH)` 또는 IntelliJ 파일 트리에서 파일 위치를 확인합니다.  
**수정:** `9-7_1.py`와 같은 폴더에 `busy_street.jpg`를 복사하거나 `IMAGE_PATH`를 실제 파일 위치로 지정합니다.

### 오류 2: `ModuleNotFoundError: No module named 'ultralytics'`

**원인:** 실행하는 가상환경에 패키지가 없습니다.  
**확인:** `python -m pip show ultralytics`  
**수정:**

```powershell
python -m pip install ultralytics opencv-python
```

### 오류 3: 자동차 크롭 또는 리사이즈 실패

**원인:** 박스 좌표가 이미지 밖으로 벗어나거나 잘라낸 영역의 가로·세로가 0일 수 있습니다.  
**확인:** `print(x1, y1, x2, y2, car_crop.shape)`  
**개선 코드 예시:** `car_crop` 생성 직전/직후에 다음을 적용할 수 있습니다.

```python
H, W = img_original.shape[:2]
x1, x2 = max(0, x1), min(W, x2)
y1, y2 = max(0, y1), min(H, y2)
if x2 <= x1 or y2 <= y1:
    continue
car_crop = img_original[y1:y2, x1:x2]
h, w = car_crop.shape[:2]
new_w = max(1, round(w * 250 / h))
resized_crop = cv.resize(car_crop, (new_w, 250))
```

기존 코드에 적용할 때에는 원래 `car_crop` 생성과 `cv.resize()` 부분을 **중복하지 말고 교체**합니다.

### 오류 4: `cv.imshow()` 창이 보이지 않음

**원인:** GUI 창 지원이 없는 OpenCV 환경이거나 원격·헤드리스 환경일 수 있습니다.  
**확인:** Windows 로컬 IntelliJ에서 실행 중인지, `opencv-python-headless` 패키지가 설치되었는지 확인합니다.  
**수정:** 일반 데스크톱 실습에서는 GUI 지원 `opencv-python`을 사용하고, 패키지 충돌이 있으면 가상환경의 OpenCV 설치를 점검합니다.
