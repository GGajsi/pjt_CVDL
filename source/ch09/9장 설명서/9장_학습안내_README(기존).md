## 학습 순서

1. **9-1 → 9-2 → 9-3:** 사진 속 물체 검출 → 웹캠 검출 → FPS 확인
2. **9-4:** 픽셀 단위 분할과 정답 마스크를 사용한 학습
3. **9-5 → 9-6:** PixelLib 의미 분할의 사진/웹캠 적용
4. **9-7 → 9-8:** PixelLib 인스턴스 분할의 사진/웹캠 적용
5. **9-9:** PyQt5를 이용한 배경 효과 비전 에이전트

## 꼭 구분할 개념

- **분류(Classification):** 사진 전체가 무엇인지 알아냅니다.
- **검출(Detection):** 물체의 종류와 네모 상자의 위치를 알아냅니다.
- **의미 분할(Semantic Segmentation):** 같은 종류를 픽셀 단위로 칠합니다.
- **인스턴스 분할(Instance Segmentation):** 같은 종류라도 물체 하나하나를 따로 칠합니다.

## 실행 준비에 대한 중요한 안내

- 9-1~9-3의 YOLOv3 가중치·설정·클래스명 파일은 첨부되지 않았습니다.
- 9-4의 Oxford Pets 데이터셋은 첨부되지 않았습니다.
- 9-5~9-9의 사전 학습 PixelLib 모델 파일은 첨부되지 않았습니다.
- 특히 9-9의 긴 `while`은 GUI 이벤트 처리를 막을 수 있어 개선 여지가 있습니다.
- 현재 버전에서 구동하려면 패키지 호환성 확인이 필요합니다. 문서의 실행 설명은 코드 동작을 해설하는 것이지 실제 실행 성공을 보증하지 않습니다.
