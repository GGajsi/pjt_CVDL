## 5. 핵심 코드 단계별 설명

### 1단계. 시간 측정 시작

```python
import time
start=time.time()
n_frame=0
```

측정 시작 시각을 기록하고 처리 개수를 0으로 만듭니다.

### 2단계. 프레임마다 개수 세기

```python
ret,frame=cap.read()
res=yolo_detect(frame,model,out_layers)
n_frame+=1
```

검출한 프레임 하나당 카운트를 1 증가시킵니다.

### 3단계. FPS 계산

```python
end=time.time()
print('초당 프레임 수=',n_frame/(end-start))
```

FPS는 초당 처리한 프레임 수입니다. `end-start`는 초 단위 경과 시간입니다.

## 6. 주요 용어 한눈에 보기

- **FPS:** 초당 처리 프레임 수
- **경과 시간:** 종료 시각에서 시작 시각을 뺀 값
- **처리량:** 일정 시간에 처리한 양

## 7. 핵심 수식 또는 계산

물체 위치는 중심 좌표와 너비·높이를 사각형의 좌상단·우하단 좌표로 바꾸어 표시합니다.

- `centerx`, `centery`: 사각형 중심의 가로·세로 좌표
- `w`, `h`: 사각형 너비·높이
- `x1 = centerx - w/2`, `y1 = centery - h/2`
- `x2 = x1 + w`, `y2 = y1 + h`

**FPS = 처리한 프레임 수 ÷ 경과 시간(초)**

- `n_frame`: 처리한 프레임의 총개수
- `end-start`: 초 단위 실행 시간
- 예: 60프레임을 20초 처리했다면 FPS는 3입니다.

## 8. 실행 준비와 주의 사항

- 카메라가 보여 주는 자체 FPS와 AI 처리 FPS는 다를 수 있습니다.
