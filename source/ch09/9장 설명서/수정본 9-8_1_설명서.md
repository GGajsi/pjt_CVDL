# 9-8_1.py 프로그램 설명서 — YOLOv8으로 사람·책 인스턴스 분할

- **기준 소스:** `9-8_1.py` (첨부된 수정본)
- **교재 연결:** 9장 프로그램 9-8(웹캠 사례/인스턴스 분할, 415쪽 부근)
- **최신 보충 내용:** 원본 PixelLib/Mask R-CNN을 **Ultralytics YOLOv8 Segmentation**으로 대체했습니다.

## 1. 선수 지식 확인

웹캠 영상 프레임, 바운딩 박스와 마스크, YOLO 물체 검출을 알고 있으면 좋습니다.

## 2. 오늘의 학습 목표

1. 의미 분할과 인스턴스 분할을 구별합니다.
2. COCO 클래스 번호로 사람과 책만 선택합니다.
3. 객체별 마스크와 바운딩 박스를 화면에 표시합니다.

## 3. 개념 비유와 흐름

**의미 분할**이 여러 사람을 모두 같은 '사람' 색으로 칠하는 것이라면, **인스턴스 분할**은 사람 A와 사람 B를 **서로 다른 개체**로 인식하고 구별할 수 있도록 마스크를 만듭니다.

```text
웹캠 → 프레임 획득 → YOLOv8s-seg 추론
    → person(0), book(73)만 필터링
    → 각 객체의 박스·마스크 표시
    → 화면 출력 → q로 종료
```

## 4. 단계별 핵심 코드

### ① 분할 모델 불러오기

```python
from ultralytics import YOLO
model = YOLO('yolov8s-seg.pt')
```

`yolov8s-seg.pt`는 사전 학습된 세그멘테이션 가중치 파일로, 처음 사용하면 다운로드될 수 있습니다. 이름의 `s`는 Small 모델을 뜻합니다. **이 코드는 새로 학습하지 않고 예측만 수행합니다.**

### ② 찾을 객체 제한

```python
target_classes = [0, 73]
```

COCO 클래스에서 `0=person`, `73=book`으로 정해져 있습니다. 다른 대상은 결과에서 걸러집니다.

### ③ 반복 처리

```python
ret, frame = cap.read()
results = model.predict(
    source=frame,
    classes=target_classes,
    conf=0.4,
    save=False,
    verbose=False
)
```

- `ret`: 프레임 획득 성공 여부
- `classes`: 분석 결과에서 선택할 클래스
- `conf=0.4`: 0.4보다 낮은 예측 점수는 제외하도록 요청
- `save=False`: 모델 추론 결과를 자동으로 파일로 저장하지 않음
- `verbose=False`: 프레임별 자세한 로그를 생략

### ④ 결과 그리기

```python
annotated_frame = results[0].plot()
cv.imshow('YOLOv8 Instance Segmentation (Person & Book)', annotated_frame)
```

`results[0]`은 입력한 한 프레임의 예측 결과입니다. `plot()`은 바운딩 박스, 객체명, 색 마스크 등이 표시된 새 이미지를 만듭니다.

### ⑤ 종료

```python
if cv.waitKey(1) & 0xFF == ord('q'):
    break
cap.release()
cv.destroyAllWindows()
```

반복문에서 빠져나온 다음 카메라와 창을 닫습니다.

## 5. 핵심 수치 이해

`conf=0.4`는 **예측을 걸러내는 임곗값**입니다. 이를 `0.7`로 높이면 더 확신하는 객체만 표시되어 검출 개수가 줄어들 수 있고, `0.25`로 낮추면 더 많은 후보가 표시될 수 있습니다. 이 수치를 **모델의 정확도 40%**라고 해석하면 안 됩니다.

## 6. 실습 방법

1. `.venv`에서 `pip install ultralytics opencv-python`을 실행합니다.
2. 웹캠 앞에 사람 또는 책을 보여 주고, 박스와 마스크가 나타나는지 봅니다.
3. 카메라 창을 클릭한 뒤 `q` 키로 종료합니다.
4. 사람과 책 외 물체가 표시되는지 관찰해 필터링 효과를 확인합니다.

## 7. 오류 해결

| 문제 | 원인/확인 | 해결 방법 |
|---|---|---|
| 웹캠 열기 실패 | `cap.isOpened()`가 False | 카메라 앱 닫기, 장치 번호 변경 |
| `.pt` 다운로드 실패 | 최초 실행 네트워크 문제 | 인터넷 확인 후 재시도 |
| 사람이 감지되지 않음 | 조명·크기·확신도 기준 | 카메라 각도 변경, `conf` 조정 |
| 화면이 끊김 | 모델이 장치에 비해 큼 | 더 가벼운 `yolov8n-seg.pt`로 비교 |


## 확인 문제 3개 (정답 대신 힌트)

1. 의미 분할과 인스턴스 분할은 무엇이 다른가요? **힌트:** 같은 종류의 물체가 두 개일 때 생각해 보세요.
2. `target_classes = [0, 73]`은 어떤 의미인가요? **힌트:** COCO 라벨 번호입니다.
3. `conf=0.4`를 0.7로 바꾸면 어떤 변화가 예상되나요? **힌트:** 통과 조건이 더 엄격해집니다.
