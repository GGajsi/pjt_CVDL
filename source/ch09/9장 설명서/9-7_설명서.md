## 5. 핵심 코드 단계별 설명

### 1단계. 모델 준비

```python
seg=instance_segmentation()
seg.load_model('mask_rcnn_coco.h5')
```

모델은 미리 학습된 것이고 별도로 재학습하지 않습니다.

### 2단계. 객체별 마스크 예측

```python
info,img_segmented=seg.segmentImage('busy_street.jpg',show_bboxes=True)
```

서로 다른 물체 인스턴스에 마스크와 바운딩 박스를 붙입니다.

### 3단계. 결과 표시

```python
cv.imshow('Image segmention overlayed',img_segmented)
```

결과를 OpenCV 창에서 확인합니다.
