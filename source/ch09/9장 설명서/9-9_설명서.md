## 5. 핵심 코드 단계별 설명

### 1단계. GUI 버튼과 선택 상자

```python
self.pickCombo.addItems(['원래 영상','흐릿(조금)','흐릿(중간)','흐릿(많이)','빨강','녹색','파랑'])
```

학생이 직접 배경 효과를 선택할 수 있습니다.

### 2단계. 카메라 연결

```python
self.cap=cv.VideoCapture(0,cv.CAP_DSHOW)
if not self.cap.isOpened(): sys.exit('카메라 연결 실패')
```

Windows의 기본 카메라를 열고 실패했는지 확인합니다.

### 3단계. 선택에 따라 효과 적용

```python
pick_effect=self.pickCombo.currentIndex()
if pick_effect==0:

    special_img=change_bg.blur_frame(frame,low=True,detect='person')
```

콤보박스 항목 번호에 따라 원본 또는 배경 흐림 등 효과를 고릅니다.

### 4단계. 효과 모델 불러오기

## 8. 실행 준비와 주의 사항

- `videoSpecialEffectFunction()`의 무한 `while`은 PyQt5 이벤트 루프를 막을 수 있어, 버튼·콤보박스·종료가 즉시 반응하지 않을 수 있습니다. `QTimer` 또는 작업 스레드로 프레임을 처리하는 개선이 필요합니다.
- `quitFunction()`에서 카메라가 아직 열리지 않았다면 `self.cap`이 없어 오류가 발생할 수 있습니다.
- `change_bg.color_frame`에서 색상 튜플의 채널 순서는 API 기준을 확인해야 하므로 표시된 빨강·파랑이 기대와 다를 수 있습니다.
- 사전 학습 모델 `xception_pascalvoc.pb` 및 PixelLib 버전 호환성을 확인해야 합니다.

**최신 보충 내용(실행 환경 참고):** TensorFlow/Keras·PixelLib·OpenCV 버전이 교재 작성 당시와 다를 수 있습니다. 원본 예제와 현재 라이브러리의 호환성을 별도로 확인해야 합니다. 본 설명서는 실제 실행 성공 여부를 확인했다고 주장하지 않습니다.
