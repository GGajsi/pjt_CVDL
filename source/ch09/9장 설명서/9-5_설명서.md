## 5. 핵심 코드 단계별 설명

### 1단계. 모델 준비

```python
seg=semantic_segmentation()
seg.load_ade20k_model('deeplabv3_xception65_ade20k.h5')
```

프로그램은 이미 학습된 `.h5` 모델을 불러옵니다. 이 코드 자체는 학습하지 않습니다.

### 2단계. 영상 분할

```python
img_fname='busy_street.jpg'
seg.segmentAsAde20k(img_fname,output_image_name='image_new.jpg')
info1,img_segmented1=seg.segmentAsAde20k(img_fname)
```

전체 영상을 픽셀별로 분류하고 결과 이미지를 생성합니다.

### 3단계. 원본과 겹쳐 보기

```python
info2,img_segmented2=seg.segmentAsAde20k(img_fname,overlay=True)
cv.imshow('Image segmention overlayed',img_segmented2)
```

`overlay=True`는 분할 결과와 원래 사진을 겹쳐 보여 줍니다.

## 8. 실행 준비와 주의 사항

- `pixellib` 및 TensorFlow/Keras의 버전 의존성이 커서 최신 환경에서는 import 오류가 날 수 있습니다. 이것은 코드 논리 오류와 별개입니다.
- `deeplabv3_xception65_ade20k.h5`와 `busy_street.jpg`를 준비해야 합니다.
- 원본은 같은 사진을 세 번 분할하므로 실행 시간이 늘어날 수 있습니다.

**최신 보충 내용(실행 환경 참고):** TensorFlow/Keras·PixelLib·OpenCV 버전이 교재 작성 당시와 다를 수 있습니다. 원본 예제와 현재 라이브러리의 호환성을 별도로 확인해야 합니다. 본 설명서는 실제 실행 성공 여부를 확인했다고 주장하지 않습니다.
