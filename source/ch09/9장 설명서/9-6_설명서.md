4. 결과를 표시하고 `output_video.mp4`로 기록합니다.

## 5. 핵심 코드 단계별 설명

### 1단계. 웹캠 열기

```python
cap=cv.VideoCapture(0)
```

기본 카메라를 엽니다. 실패 여부 검사는 원본에 없습니다.

### 2단계. 모델 로드

```python
seg_video=semantic_segmentation()
seg_video.load_ade20k_model('deeplabv3_xception65_ade20k.h5')
```

모델은 사전 학습되어 있으며 별도의 학습 과정은 없습니다.

### 3단계. 실시간 처리와 저장

```python
seg_video.process_camera_ade20k(cap,overlay=True,frames_per_second=2,output_video_name='output_video.mp4',show_frames=True,frame_name='Pixellib')
```

출력 영상을 저장하면서 분할 프레임을 보여 줍니다. `frames_per_second=2`는 이 함수에 지정한 출력 프레임 속도 설정으로, 컴퓨터의 실제 처리 성능을 뜻하지 않습니다.

## 8. 실행 준비와 주의 사항

- 카메라가 열리지 않았을 때를 확인하는 코드가 없습니다.
