# MOT17 8개 실습 + 공통 모듈 설명서

첨부된 Python 소스 파일을 실제로 확인하여 정리한 수업용 문서입니다.

## 권장 학습 순서

| 순서 | 프로그램 | 핵심 개념 |
|---|---|---|
| 01 | `01_show_frames.py` | 연속 이미지 재생 |
| 02 | `02_show_ground_truth.py` | 정답(GT) 시각화 |
| 03 | `03_detection_viewer.py` | Detection 및 confidence |
| 04 | `04_tracking_trajectory.py` | IoU 기반 tracking / 궤적 |
| 05 | `05_line_crossing_counter.py` | 가상선 통과 카운팅 |
| 06 | `06_pedestrian_heatmap.py` | 누적 위치 히트맵 |
| 07 | `07_optical_flow.py` | Farnebäck Optical Flow |
| 08 | `08_yolo_bytetrack.py` | YOLO11 및 ByteTrack |
| 공통 | `mot17_common.py` | 데이터 로드·FPS·간단 추적기 |

## 데이터 경로의 중요한 차이

- **01, 02**: `datasets/MOT17/train/MOT17-13-SDP`를 직접 참조합니다.
- **03~08**: `mot17_common.py`에 지정된 `datasets/MOT17/train/MOT17-11-SDP`를 참조합니다.
- **02**는 정답 `gt/gt.txt`를 사용합니다. **03~06**은 검출 `det/det.txt`를 사용합니다.
- **07**은 이미지로 Optical Flow를 계산하며 `det.txt`를 사용하지 않습니다.
- **08**은 YOLO가 이미지를 직접 검출하므로 `det.txt`를 사용하지 않습니다.
- **04~05**의 `Tracker`와 **08**의 `ByteTrack`은 서로 다른 방식입니다.

## 라이브러리 설치 예시

```powershell
python -m pip install opencv-python numpy pandas scipy ultralytics
```

08의 첫 실행 시 `yolo11n.pt` 모델 파일 및 필요한 추적 의존 패키지가 추가로 다운로드·설치될 수 있습니다. 일부 시퀀스에는 공개 Ground Truth가 없으므로 02번은 train을 대상으로 합니다.

## 파일 구성

각 설명서는 **프로그램 개요 → 학습목표 → 준비 사항 → 처리 순서 → 핵심 코드 → 실행 방법 → 주의점 → 실습 과제 → 한 줄 요약** 순서로 구성되어 있습니다.
