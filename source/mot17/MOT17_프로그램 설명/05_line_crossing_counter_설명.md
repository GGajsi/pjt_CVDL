# 05. 가상선 통과 인원 카운팅

> 대상 소스: `05_line_crossing_counter.py`  
> 대상: 컴퓨터 비전·객체 추적 입문 학습자  
> 데이터: MOT17 (실제 소스 기준)

## 1. 프로그램 개요
사람의 박스 하단 중앙점이 화면 중간의 가상선을 상하로 통과하면 ID별로 방향 카운터를 증가시킵니다.

## 2. 학습목표
- 가상선의 위치와 교차 조건을 구현할 수 있습니다.
- 동일 ID의 중복 집계를 막는 집합(set)의 용도를 설명할 수 있습니다.

## 3. 준비 사항
- Python, `opencv-python`, `pandas`, `numpy`, `scipy`
- 공통 모듈 및 **MOT17-11-SDP train** 데이터 필요

## 4. 처리 순서
1. 프레임 높이의 50% 지점에 가로선 생성
2. 검출 결과 추적 및 하단 중앙 y좌표 계산
3. 이전 y와 현재 y 비교
4. 위→아래 / 아래→위 교차 각각 집계
5. 화면과 콘솔에 누적 수 표시

## 5. 핵심 코드와 설명
```python
line_y = int(h * LINE_RATIO)
if old_y < line_y <= y and tid not in crossed_down:
    count_down += 1
if old_y > line_y >= y and tid not in crossed_up:
    count_up += 1
```
- 영상에서 y좌표는 **아래로 갈수록 커집니다**.
- `previous_y`: 직전 관측 y 저장
- `crossed_down`, `crossed_up`: **방향별로 한 ID당 최대 한 번** 카운트
- `LINE_RATIO=0.5`: 영상 중간 높이

## 6. 실행 방법 및 화면 확인
Windows PowerShell에서 프로젝트의 가상환경을 활성화한 후 프로젝트 루트에서 실행합니다. 예: `python source/mot17/05_line_crossing_counter.py`. 실제 파일 위치가 다르면 경로를 수정합니다. **ESC** 키로 종료합니다. 데이터는 `datasets/MOT17` 아래에 배치하고, `BASE_DIR = Path(__file__).resolve().parents[2]`가 프로젝트 루트를 가리키는지 확인합니다. 노란 가로선과 `DOWN`, `UP` 누적 개수가 표시됩니다. 종료 후 콘솔에도 출력됩니다.

## 7. 주의할 점과 한계
- 카운터는 실제 보행 인원보다 ID 안정성에 영향을 받습니다.
- 하나의 ID는 같은 방향으로 두 번 통과해도 다시 집계되지 않습니다.
- 추적이 끊겨 새 ID가 발급되면 중복될 수 있습니다.
- 이전 좌표가 교차선에 정확히 닿는 특수 상황은 비교 연산자에 따라 집계 결과가 달라질 수 있습니다.
