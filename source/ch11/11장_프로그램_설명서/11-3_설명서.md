# 11-3 — 사전 학습된 Hugging Face ViT 이미지 분류

> 주 교재: 『컴퓨터 비전과 딥러닝』 11장 **비전 트랜스포머**(PDF 481쪽부터), **11-5 비전 트랜스포머 프로그래밍 실습**(PDF 531쪽부터). 이 자료는 업로드된 `11-3.py`의 실제 코드에 근거합니다. 교재 페이지는 관련 개념·실습을 찾아보기 위한 위치입니다.

## 1. 선수 지식 확인

분류 모델의 `logits`와 `softmax`가 서로 다른 개념임을 알고 있나요?

## 2. 오늘의 학습 목표

1. 사전 학습 모델을 불러와 훈련 없이 이미지 분류한다.
2. ImageProcessor의 역할과 출력 확률을 구분한다.
3. 세 장의 사진에 대해 1순위 예측 결과를 확인한다.

## 3. 핵심 개념 — 일상 비유

이미 수많은 사진으로 훈련한 **전문 감별사**에게 새 사진을 바로 보여 주는 것입니다. 사진 크기와 색을 감별사가 이해하는 형태로 준비하는 직원이 `ImageProcessor`입니다.

## 4. 프로그램 처리 흐름

```text
BSDS 이미지 3장(PIL) → ViTImageProcessor
→ google/vit-base-patch16-224 (TensorFlow)
→ logits → argmax + softmax → 이름/확률 출력
```

## 5. 핵심 수식과 기호

$p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}$. **zᵢ**는 i번째 클래스의 원시 점수(logit), **pᵢ**는 변환된 확률형 점수입니다. 모든 $p_i$의 합은 1입니다. `argmax`는 가장 큰 점수의 클래스 인덱스를 선택합니다.

## 6. 실제 코드 단계별 해설

**① 입력:** `Image.open`으로 `BSDS_242078.jpg`, `BSDS_361010.jpg`, `BSDS_376001.jpg` 세 장을 엽니다.

**② 사전 학습 모델:** `ViTImageProcessor.from_pretrained('google/vit-base-patch16-224')`, `TFViTForImageClassification.from_pretrained(...)`를 사용합니다.

**③ 추론:** `inputs=feature_extractor(img, return_tensors='tf')`, `res=model(**inputs)`를 수행합니다. 별도의 학습 코드는 없습니다.

**④ 해석:** `argmax(res.logits[i])`로 예측 인덱스, `tf.nn.softmax(...)`로 확률형 점수를 출력하고 `model.config.id2label`로 클래스 이름을 표시합니다.

## 7. 실행 준비와 방법

필요 파일 3개를 **실행 작업 디렉터리**에 준비합니다. 패키지: `python -m pip install tensorflow transformers pillow matplotlib`. 최초 실행 시 모델 다운로드가 필요합니다. `TFViTForImageClassification`은 Transformers/TensorFlow/Keras 버전에 따라 호환성 문제가 있을 수 있습니다.

## 8. 코드 검토 및 오류 해결(원인 → 확인 → 수정)

- **원인 ① — 이미지 파일 누락:** `Image.open(...)`에서 오류. **확인:** IDE Working directory와 실제 3개 JPG 위치. **수정:** `Path(__file__).resolve().parent / 'BSDS_...'` 방식으로 경로를 고정합니다.
- **원인 ② — TensorFlow 기반 Transformers 버전 충돌:** 모델 객체 생성 단계의 예외. **확인:** `python -m pip show transformers tensorflow keras tf-keras`. **수정(최신 보충 내용):** 호환 버전으로 전용 가상환경을 구성하거나 PyTorch `ViTForImageClassification`로 실습을 별도 변경합니다. 원본 소스와 구별해야 합니다.
- **원인 ③ — 느린 최초 실행:** 가중치 다운로드 및 초기화 시간. **확인:** 네트워크 및 모델 캐시. **수정:** 다운로드 후 캐시가 유지되는지 확인합니다.

## 9. 확인 문제 3개 — 정답 대신 힌트

1. **왜 11-3은 `fit()`이 없나요?** 힌트: `from_pretrained`.
2. **`logits`가 곧 확률일까요?** 힌트: 합계가 1인지 확인.
3. **이미지 3장을 한 번에 처리하는 것은 무엇이라고 부를까요?** 힌트: 배치 입력.

## 10. 미니 과제

자체 사진 한 장으로 교체한 뒤 예측 라벨과 확률을 기록하세요. ImageNet의 분류 범주와 맞지 않는 사진에서는 엉뚱한 답이 나올 수 있음을 적어 보세요.

## 11. 오늘의 핵심 요약

사전 학습 ViT는 이미지 전처리 → 모델 추론 → 클래스 해석으로 실행합니다. 출력 점수는 `softmax`를 거쳐 확률형 점수가 됩니다.
