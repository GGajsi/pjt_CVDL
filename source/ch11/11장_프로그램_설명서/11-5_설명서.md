# 11-5 — CLIP 이미지와 문장 사이의 유사도 비교

> 주 교재: 『컴퓨터 비전과 딥러닝』 11장 **비전 트랜스포머**(PDF 481쪽부터), **11-5 비전 트랜스포머 프로그래밍 실습**(PDF 531쪽부터). 이 자료는 업로드된 `11-5.py`의 실제 코드에 근거합니다. 교재 페이지는 관련 개념·실습을 찾아보기 위한 위치입니다.

## 1. 선수 지식 확인

이미지 분류와 자연어 문장 입력의 차이를 이해했나요?

## 2. 오늘의 학습 목표

1. 이미지와 문장을 함께 처리하는 CLIP의 목적을 설명한다.
2. 네 문장 후보 가운데 이미지에 가장 맞는 것을 찾는다.
3. softmax 값이 절대적인 사실 확률을 의미하지 않음을 이해한다.

## 3. 핵심 개념 — 일상 비유

사진 한 장과 4장의 설명 카드를 탁자에 놓고 **가장 잘 어울리는 카드**를 고르는 활동입니다. 새 학습 없이 후보 문장만 바꿔 다른 주제를 테스트할 수 있습니다.

## 4. 프로그램 처리 흐름

```text
BSDS_361010.jpg + 영어 후보 문장 4개
→ CLIPProcessor(이미지·텍스트 변환)
→ openai/clip-vit-base-patch32
→ logits_per_image → softmax(dim=1)
→ 후보별 상대 점수(%) 출력
```

## 5. 핵심 수식과 기호

$p_i=\exp(s_i)/\sum_{j=1}^{m}\exp(s_j)$. **sᵢ**는 이미지와 i번째 문장의 유사도 기반 점수, **m**은 후보 문장 수(현재 4), **pᵢ**는 **이 4개 후보 안에서의 상대 점수**입니다. 후보 문장을 바꾸면 점수도 달라집니다.

## 6. 실제 코드 단계별 해설

**① 사진:** `BSDS_361010.jpg`를 PIL로 읽습니다.

**② 비교 문장 4개:** 소스에 `Two horses are running on grass`, `Students are eating`, `Croquet playing on horses`, `Golf playing on horses`가 입력돼 있습니다.

**③ 모델:** `CLIPProcessor.from_pretrained('openai/clip-vit-base-patch32')`, `CLIPModel.from_pretrained(...)`.

**④ 입력:** `processor(text=captions,images=img,return_tensors='pt',padding=True)`가 사진과 문장을 텐서로 만듭니다.

**⑤ 결과:** `res.logits_per_image`를 `softmax(dim=1)`로 변환하고 문장별 점수를 출력합니다.

## 7. 실행 준비와 방법

`python -m pip install transformers torch pillow matplotlib`. 이미지 파일과 모델 다운로드 환경이 필요합니다. 영어 후보 설명은 사용자 사진 내용에 맞게 바꿔 사용할 수 있습니다.

## 8. 코드 검토 및 오류 해결(원인 → 확인 → 수정)

- **원인 ① — 상대 점수 오해:** 90%를 ‘현실 세계에서 90% 사실’로 받아들이는 경우. **확인:** 문장 후보를 바꾸면 점수도 바뀝니다. **수정:** ‘제시된 후보 간 상대 점수’라고 설명합니다.
- **원인 ② — 경로/다운로드:** 파일 또는 모델 누락. **확인:** 실행 작업 폴더, Hugging Face 캐시, 인터넷. **수정:** 경로 고정과 네트워크 확인.
- **최신 보충 내용:** 평가/추론 전용 실행에서는 `model.eval()` 및 `torch.inference_mode()`를 사용하는 것을 권장합니다. 첨부 소스는 이 구문 없이 실행합니다.

## 9. 확인 문제 3개 — 정답 대신 힌트

1. **CLIP은 전통적인 10개 클래스 분류와 어떤 점이 다른가요?** 힌트: 사용자가 문장 후보를 직접 입력.
2. **softmax 점수의 합은 얼마인가요?** 힌트: 후보 수가 4여도 변하지 않는 값.
3. **문장 후보를 변경하면 같은 이미지의 점수도 바뀔까요?** 힌트: 상대 비교.

## 10. 미니 과제

자신이 선택한 사진에 맞게 문장 4개를 작성한 뒤, 설명의 구체성에 따라 점수가 어떻게 변하는지 관찰하세요.

## 11. 오늘의 핵심 요약

CLIP은 이미지와 텍스트 사이의 관련성을 비교합니다. 출력 백분율은 **주어진 문장 후보들 안에서의 상대 점수**입니다.
