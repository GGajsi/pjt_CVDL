## 6. 핵심 수식

- **패치 수:** $P=(H/p)(W/p)$; **H/W** 이미지 높이/너비, **p** 패치 한 변, **P** 패치 개수입니다. 11-1은 64개, 11-2는 144개입니다.
- **주목:** $\operatorname{softmax}(QK^T/\sqrt{d_k})V$; **Q** 질의, **K** 비교 기준, **V** 전달 값, **dₖ** Key 차원입니다.
- **softmax:** $p_i=\exp(z_i)/\sum_j\exp(z_j)$; **zᵢ** 원시 점수, **pᵢ** 정규화된 점수입니다.

## 8. 반드시 확인할 코드 사항

1. **11-1/11-2:** `return model`과 분류 헤드가 `for _ in range(N)` 안에 있으므로 설정한 6개가 아니라 **1개 인코더만 생성**됩니다. 들여쓰기를 바로잡고 `model.summary()`를 확인해야 합니다.
2. **11-1/11-2:** 마지막 층이 `softmax`인데 `SparseCategoricalCrossentropy(from_logits=True)`를 사용합니다. `from_logits=False`로 수정합니다.
3. **11-4:** 정규화 박스를 실제 이미지 크기 대신 `481`, `321`로 계산하며, 신뢰도 필터가 충분하지 않습니다. 수정본 `11-4_1`의 공식 후처리 함수를 우선 참고하세요.
4. **11-3:** `TFViTForImageClassification`은 Transformers/TensorFlow/Keras 버전 호환성을 확인해야 합니다.
5. **11-5:** CLIP의 백분율은 제시된 **4개 문장 안에서만 비교되는 상대 점수**입니다.
6. **최신 보충 내용:** 추론에는 `model.eval()` 및 `torch.inference_mode()` 활용이 유리하며, 학습 데이터/검증 데이터/최종 테스트 데이터를 분리하면 성능 평가가 더 정확해집니다.

## 9. 원본과 수정본 비교

`11-4.py`는 `DetrFeatureExtractor`와 수동 좌표 복원을 사용하는 반면, **`11-4_1.py`는 `DetrImageProcessor`와 `post_process_object_detection()`**을 사용합니다. 반환 결과에 포함된 점수·레이블·픽셀 좌표를 바로 시각화합니다. 모델의 이름은 둘 다 `facebook/detr-resnet-50`이므로 다른 모델의 성능 비교가 아니라 **후처리 개선 비교**입니다.

## 10. 확인 문제 3개 (힌트 제공)

1. **11-1과 11-2의 패치 개수는 왜 다를까요?** 힌트: `(이미지 한 변 / 패치 한 변)^2`를 계산합니다.
2. **ViT 이미지 분류와 DETR 물체 검출은 출력이 어떻게 다를까요?** 힌트: 이미지 한 장의 이름과 여러 물체의 사각형을 비교합니다.
3. **CLIP 후보 문장을 바꾸면 기존 사진의 점수가 달라질까요?** 힌트: 점수는 제시된 후보 전체에 대해 softmax 처리됩니다.
