# 11-4_1 — DETR 이미지 물체 검출 — 후처리 개선 수정본

> 주 교재: 『컴퓨터 비전과 딥러닝』 11장 **비전 트랜스포머**(PDF 481쪽부터), **11-5 비전 트랜스포머 프로그래밍 실습**(PDF 531쪽부터). 이 자료는 업로드된 `11-4_1.py`의 실제 코드에 근거합니다. 교재 페이지는 관련 개념·실습을 찾아보기 위한 위치입니다.

## 1. 선수 지식 확인

11-4에서 logits/박스 좌표와 신뢰도 임계값을 이해했나요?

## 2. 오늘의 학습 목표

1. `DetrImageProcessor`로 입력을 전처리한다.
2. `post_process_object_detection`으로 좌표와 임계값을 다룬다.
3. 모델 예측을 OpenCV 사각형으로 시각화한다.

## 3. 핵심 개념 — 일상 비유

검출 모델이 적어 낸 메모(원시 logits와 좌표)를 **정리 담당자**가 실제 사진 크기에 맞는 위치와 신뢰도 70% 이상의 목록으로 정돈하는 과정입니다.

## 4. 프로그램 처리 흐름

```text
PIL RGB 이미지 → DetrImageProcessor → DETR 추론
→ post_process_object_detection(threshold=0.7, 실제 이미지 크기)
→ scores/labels/boxes → OpenCV BGR 변환 → 박스+라벨
```

## 5. 핵심 수식과 기호

임계값 판정은 $s\ge\tau$입니다. **s**는 후처리된 객체 예측 점수, **τ**는 신뢰도 임계값입니다. 코드에서는 `threshold=0.7`을 사용합니다. 박스는 `(x_min,y_min,x_max,y_max)` 픽셀 좌표로 돌려받습니다.

## 6. 실제 코드 단계별 해설

**① 모델:** `DetrImageProcessor`, `DetrForObjectDetection`에서 `facebook/detr-resnet-50`을 불러옵니다.

**② 추론:** `inputs=processor(images=img, return_tensors='pt')`, `outputs=model(**inputs)`를 실행합니다.

**③ 후처리:** `target_sizes=torch.tensor([img.size[::-1]])`로 실제 `(높이, 너비)`를 지정하며 `post_process_object_detection(..., threshold=0.7)[0]`로 필터링합니다.

**④ 결과:** `results['scores']`, `['labels']`, `['boxes']`를 함께 순회합니다.

**⑤ 표시:** `cv.COLOR_RGB2BGR`로 바꾸고 박스·이름·확률(%)을 표시합니다. `label.item() % 100`으로 색 배열 접근을 제한합니다.

## 9. 확인 문제 3개 — 정답 대신 힌트

1. **`img.size[::-1]`이 필요한 까닭은?** 힌트: PIL은 너비·높이, 후처리는 높이·너비.
2. **0.7 임계값을 0.5로 낮추면 어떤 변화가 예상되나요?** 힌트: 검출 수와 오검출.
3. **OpenCV로 표시하기 전에 RGB→BGR 변환을 하는 이유는?** 힌트: 라이브러리의 채널 순서.
