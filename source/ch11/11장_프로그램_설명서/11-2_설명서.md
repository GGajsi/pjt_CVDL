# 11-2 — 이미지 확대·증강을 더한 ViT 분류기

> 주 교재: 『컴퓨터 비전과 딥러닝』 11장 **비전 트랜스포머**(PDF 481쪽부터), **11-5 비전 트랜스포머 프로그래밍 실습**(PDF 531쪽부터). 이 자료는 업로드된 `11-2.py`의 실제 코드에 근거합니다. 교재 페이지는 관련 개념·실습을 찾아보기 위한 위치입니다.

## 1. 선수 지식 확인

11-1의 패치 개수 계산과 CNN/ViT 분류의 차이를 설명할 수 있나요?

## 2. 오늘의 학습 목표

1. 32×32 영상을 72×72로 확대한 목적을 이해한다.
2. RandomFlip/Rotation/Zoom 데이터 증강을 설명한다.
3. 11-1과 패치 수·연산량·실행 결과를 비교한다.

## 3. 핵심 개념 — 일상 비유

같은 풍경 사진을 크게 인화하고, 좌우 반전·살짝 회전·확대하여 연습하는 것입니다. 사진 수를 실제로 늘리는 대신 매 학습 단계에서 변형합니다.

## 4. 프로그램 처리 흐름

```text
CIFAR-10 32×32 → Normalization → Resize(72×72)
→ 좌우반전/회전/줌 → 6×6 패치 144개 → 임베딩
→ Transformer 인코더 → 분류 헤드 → 10개 클래스
→ 학습/평가/accuracy_graph.png, loss_graph.png
```

## 5. 핵심 수식과 기호

이미지 패치 개수: $P=(H/p)\times(W/p)$. 여기서 **H**는 이미지 높이, **W**는 너비, **p**는 한 패치의 한 변 크기, **P**는 전체 패치 개수입니다.

어텐션: $\operatorname{Attention}(Q,K,V)=\operatorname{softmax}(QK^T/\sqrt{d_k})V$. **Q**는 찾고 싶은 정보(Query), **K**는 비교할 단서(Key), **V**는 실제 전달할 정보(Value), **d_k**는 Key 벡터의 차원입니다. 여러 헤드가 서로 다른 관계를 병렬 학습합니다.

$P=(72/6)^2=144$개입니다. 하나의 패치는 $6\times6\times3=108$개 원본 값이며, 임베딩은 64차원입니다. 주목의 비교 연산량은 토큰 수 $P$의 **제곱**에 비례하므로, 11-1의 64개에서 144개로 증가하면 해당 부분 연산량이 대략 $(144/64)^2=5.06$배가 될 수 있습니다(전체 실행 시간 배수가 아님).

## 6. 실제 코드 단계별 해설

**① 입력 확대:** `Resizing(72,72)`로 패치 분할 전에 입력 크기를 변경합니다. 확대했다고 새로운 정보가 생기는 것은 아닙니다.

**② 데이터 증강:** `RandomFlip('horizontal')`, `RandomRotation(0.02)`, `RandomZoom(0.2)`는 훈련 중 영상을 다양하게 만듭니다.

**③ 패치:** `patch_siz=6`, `p2=144`, `d_model=64`입니다.

**④ 주목:** `h=8`, `N=6`로 정의돼 있지만 **현재 코드에서는 return의 들여쓰기로 첫 블록만 구성**됩니다.

**⑤ 학습 및 그래프:** CIFAR-10, `epochs=100`, `batch_size=128`을 사용하며 그래프 파일명을 11-1과 동일하게 지정하여 같은 작업 디렉터리에서는 덮어쓸 수 있습니다.

## 7. 실행 준비와 방법

TensorFlow/Matplotlib가 필요합니다. CIFAR-10은 첫 실행 시 인터넷 다운로드가 필요할 수 있습니다. CPU에서는 100 epochs 학습이 길어질 수 있으므로 1 epoch로 구조를 검증하세요.

## 8. 코드 검토 및 오류 해결(원인 → 확인 → 수정)

- **원인 ① — 모델 생성 코드의 들여쓰기:** 현재 `model=keras.Model(...)`과 `return model`이 `for _ in range(N):` **안에 있습니다.** 따라서 설정값 `N=6`과 달리 실제 인코더 블록은 **첫 번째 블록만 만들어진 뒤 함수가 종료**됩니다. **확인:** 해당 두 줄의 들여쓰기와 `model.summary()`의 MultiHeadAttention 개수를 비교하세요. **수정:** 두 줄을 반복문 **밖으로 한 단계 내리고**, 반복문 뒤에 분류 헤드를 둡니다.
- **원인 ② — 손실 함수와 출력의 불일치:** 출력층이 `softmax`인데 손실 함수가 `SparseCategoricalCrossentropy(from_logits=True)`입니다. **확인:** `Dense(n_class, activation='softmax')`. **수정:** `from_logits=False`로 변경하거나 기본 `SparseCategoricalCrossentropy()`를 사용합니다.
- **원인 ③ — 학습용 정규화 층:** `Normalization()` 층은 `adapt(x_train)`으로 통계값을 학습하며, `/255`와는 다릅니다. **확인:** `model.layers[1].adapt(x_train)` 및 입력 형식을 점검합니다.
- **최신 보충 내용:** `validation_data=(x_test, y_test)`는 학습 중 모델 선택용 검증에 테스트 데이터를 사용하는 방식입니다. 일반적인 성능 평가에서는 훈련/검증/최종 테스트를 분리하세요. 학습 전에 `epochs=1`로 동작 점검을 권장합니다.
- **원인 ④ — 그래프 덮어쓰기:** 11-1과 같은 파일명으로 저장합니다. **확인:** `accuracy_graph.png`와 `loss_graph.png`. **수정:** `11-2_accuracy_graph.png`처럼 파일명을 바꿉니다.
