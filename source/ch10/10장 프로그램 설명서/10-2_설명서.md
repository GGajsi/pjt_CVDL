## 3. 핵심 개념 — 쉬운 비유

운동장에서 특정 선수의 옷에 표시를 붙이고 매 장면 그 표시를 따라가는 것입니다.

### 처리 흐름

```text
비디오 → 첫 프레임 특징점 검출 → Lucas-Kanade 광류 → 점·궤적 표시 → 다음 프레임
```

### 주요 원리

Shi–Tomasi로 좋은 특징점을 고르고, 피라미드 Lucas–Kanade로 특징점의 다음 위치를 추적합니다. `mask`에 궤적을 누적합니다.

### 핵심 표현

``cv.goodFeaturesToTrack()` / `cv.calcOpticalFlowPyrLK()``

## 4. 핵심 수식 또는 계산 관점

물체의 영상상 이동은 \(\Delta x = x_t-x_{t-1}\), \(\Delta y=y_t-y_{t-1}\)처럼 표현할 수 있습니다. 여기서 \(x_t,y_t\)는 현재 프레임의 좌표, \(x_{t-1},y_{t-1}\)는 이전 프레임의 좌표, \(\Delta x,\Delta y\)는 두 시점 사이의 위치 변화입니다. 모든 프로그램이 이 식을 직접 계산하지는 않으며, 추적 개념을 이해하기 위한 기본식입니다.

## 5. Python/OpenCV 단계별 코드 읽기

첨부 소스에서 중요 함수가 호출되는 지점입니다. **왼쪽은 원본의 줄 번호**이며 전체 코드는 `10-2.py`를 참고하세요.

```python
  13 | p0=cv.goodFeaturesToTrack(old_gray,mask=None,**feature_params)
  22 | p1,match,err=cv.calcOpticalFlowPyrLK(old_gray,new_gray,p0,None,**lk_params)	# 광류 계산
```

**단계 1.** 입력 영상 또는 카메라와 모델을 준비합니다.  
**단계 2.** 필요한 색상 변환·특징점 검출·모델 입력 전처리를 수행합니다.  
**단계 3.** 핵심 추론/추적을 실행합니다.  
**단계 4.** 예측 결과를 그림이나 선으로 표시합니다.  
**단계 5.** 키 입력으로 종료하고 자원을 해제합니다.

## 7. 예상 오류 — 원인 → 확인 → 수정

**원인:** 비디오 최초 프레임을 읽지 못하면 `cvtColor`에서 오류가 납니다. 특징점이 사라져 `p1`이 `None`이면 기존 코드의 `good_new`가 정의되지 않을 수 있으며, 추적점 소진 시 재검출이 필요합니다.

**확인:** Python 실행 창의 첫 오류 줄과 입력 파일/모델 경로, 카메라 상태, 배열 모양(`shape`)을 확인합니다.

**수정:** 문제가 발생한 경로·객체·입력 모양부터 고치고 다시 실행합니다. 원본 코드에 없는 자동 복구 기능이 이미 존재한다고 가정하지 마세요.
