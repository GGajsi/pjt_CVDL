## 2. 선수 지식과 학습 목표

선수 지식은 OpenCV 이미지 처리, BGR/RGB, 영상 프레임 반복 처리, NumPy 배열, 딥러닝 모델 추론입니다. 학습 후에는 광류와 추적을 구분하고, 얼굴·손·자세 랜드마크 및 AR 합성을 설명할 수 있어야 합니다.

## 3. 추천 수업 순서

1. **10-1 → 10-2:** 밀집 광류와 희소 특징점 추적
2. **10-3 → 10-3_1:** YOLOv3+SORT와 YOLOv8+BoT-SORT 비교
3. **10-4 → 10-4_1 → 10-5 → 10-5_1:** 사진/웹캠 얼굴 검출과 대체 알고리즘 비교
4. **10-6 → 10-6_1:** 오른쪽 눈 기준 AR 장신구 합성
5. **10-7 → 10-7_1 → 10-8 → 10-9:** 얼굴 메시·손·자세 랜드마크 분석

## 5. 라이브러리 설치 안내 — 사용자 환경 반영

기존 프로젝트 가상환경에서 아래 세 패키지 버전을 맞추어 사용하셨습니다. **프로젝트의 다른 패키지에 영향을 줄 수 있으므로** 변경 전 `python -m pip freeze > requirements_backup.txt`로 백업하세요.

```powershell
python -m pip uninstall tensorflow mediapipe protobuf -y
python -m pip install tensorflow==2.15.0
python -m pip install mediapipe==0.10.14
python -m pip install protobuf==4.25.8
python -m pip check
```

- 기준: TensorFlow 2.15.0, MediaPipe 0.10.14, protobuf 4.25.3. Python 버전과 나머지 패키지까지 포함하여 호환성이 결정되므로 **모든 조합에서 무조건 작동한다고 보장하지 않습니다**.
- 기존 10장 MediaPipe 소스의 `mp.solutions` API를 유지하기 위한 선택입니다.
- `10-3_1.py`에는 별도로 `ultralytics`가 필요합니다. `10-4_1.py`, `10-5_1.py`, `10-6_1.py`는 OpenCV를 사용하며, 각각 필요한 XML/Caffe/ONNX 모델이 다릅니다.
- `10-9.py`의 `plot_landmarks()`를 활용하려면 Matplotlib 설치 여부도 확인하세요.

```powershell
python -m pip install numpy opencv-python ultralytics matplotlib
python -c "import tensorflow as tf, mediapipe as mp, google.protobuf; print(tf.__version__, mp.__version__, google.protobuf.__version__)"
```

## 8. 실행 중 확인해야 할 문제

| 현상 | 원인 → 확인 → 수정 |
|---|---|
| `ModuleNotFoundError: mediapipe` | 실행 Python과 설치된 가상환경 확인 → 해당 `.venv`로 실행 및 버전 재설치 |
| `AttributeError: module 'mediapipe' has no attribute 'solutions'` | MediaPipe 버전·설치 위치 확인 → `0.10.14` 환경 및 패키지 충돌 점검 |
| TensorFlow oneDNN / CUDA 경고 | 실제 오류인지 로그 하단의 Traceback으로 확인 → 실행되면 무시 가능; GPU 여부와 구분 |
| `FileNotFoundError` / 빈 프레임 | 파일의 현재 작업 디렉터리 또는 카메라 상태 확인 → 절대경로/소스 경로 사용 |
| `10-2`의 추적점 관련 오류 | `p1 is None`, 추적점 소진 여부 확인 → 특징점 재검출 로직 추가 |
| `10-3` SORT 배열 크기 오류 | `sort.update()`가 Nx5를 요구하는지 확인 → `[x1,y1,x2,y2,score]`로 전달 |
| `10-6_1` NumPy broadcast 오류 | 주사위 크기와 ROI 크기 비교 → 이미지 폭·높이 기준으로 슬라이스 조정 |
| `10-9` 종료 시 그래프 오류 | `res.pose_world_landmarks is None`인지 확인 → 검출되었을 때만 플롯 |

## 9. 확인 문제 3개 — 먼저 힌트만

1. **광류(10-1)와 KLT 추적(10-2)은 어떻게 다른가요?**  
   힌트: 모든 픽셀을 계산하는지, 특징점만 계산하는지 생각하세요.
2. **객체 검출과 다중 객체 추적은 왜 분리해 생각해야 할까요?**  
   힌트: 객체가 잠시 가려졌다 다시 나타나는 경우를 생각하세요.
3. **AR 장신구를 눈 위치에 놓으려면 무엇이 필요할까요?**  
   힌트: 눈 좌표, PNG 크기, 투명도(alpha)입니다.
