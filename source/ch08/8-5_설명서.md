           ↓

           ↓

           ↓

## 5. 코드를 단계별로 아주 쉽게 이해하기

### ① 라이브러리 가져오기

```python
import tensorflow.keras.datasets as ds
from tensorflow.keras.preprocessing.image import ImageDataGenerator
import matplotlib.pyplot as plt
```

| 코드 | 역할 | 비유 |
|---|---|---|
| `datasets` | 실습용 사진과 정답 불러오기 | 사진 앨범 꺼내기 |
| `ImageDataGenerator` | 사진의 모양을 무작위로 바꾸기 | 사진 편집기 |
| `matplotlib.pyplot` | 사진들을 화면에 배열해 보여 주기 | 전시판 |

### ② CIFAR-10 불러오고 사진 값 조정하기

```python
(x_train,y_train),(x_test,y_test)=ds.cifar10.load_data()
x_train=x_train.astype('float32'); x_train/=255
```

- `x_train`: 학습용 컬러 사진 **50,000장**, 사진 하나의 크기는 **32×32×3**입니다.
- `y_train`: 각 사진의 정답 숫자. 모양(shape)은 **(50000, 1)**입니다.
- `x_test`, `y_test`: 테스트용 데이터. 이 실습에서는 직접 사용하지 않습니다.
- `astype('float32')`: 소수점 숫자로 변환합니다.
- `/=255`: 픽셀의 밝기 값 **0~255를 0~1로 조정**합니다. 예: 255→1.0, 0→0.0.

### ③ 앞의 15장만 선택하기

```python
x_train=x_train[0:15,]
y_train=y_train[0:15,]
```

`[0:15]`는 **0번째부터 14번째까지**, 총 15개를 뜻합니다. 사진과 정답을 **같은 위치에서** 골라야 서로 맞습니다.

### ④ 종류별 이름 준비하기

```python
class_names=['airplane','automobile','bird','cat','deer',
             'dog','flog','horse','ship','truck']
```

컴퓨터는 비행기를 `0`, 자동차를 `1`, 새를 `2`와 같은 **숫자 정답**으로 기억합니다. `class_names`는 숫자를 사람이 읽을 **이름**으로 바꿉니다.

**주의:** 제공하신 코드에서 `flog`는 오타입니다. `frog`(개구리)로 고치면 제목이 올바르게 표시됩니다. (분류용 숫자 정답은 바뀌지 않습니다.)

### ⑤ 원본 사진 15장 출력하기 — 첫 번째 핵심 수정

```python
plt.figure(figsize=(20,2))
plt.suptitle('First 15 images in the train set')
for i in range(15):
    plt.subplot(1,15,i+1)
    plt.imshow(x_train[i])
    plt.xticks([]); plt.yticks([])
    plt.title(class_names[int(y_train[i, 0])])
plt.show()
```

- `plt.figure(figsize=(20,2))`: 그림판 크기 설정.
- `plt.subplot(1,15,i+1)`: **1행 15열** 중 현재 사진을 놓을 칸 선택.
- `plt.imshow(x_train[i])`: `i`번째 사진 출력.
- `xticks([]), yticks([])`: 눈금 표시 생략.
- `plt.title(...)`: 사진 위에 이름 표시.
- `plt.show()`: 완성한 화면 보여 주기.

#### 왜 `y_train[i]`가 아니라 `y_train[i, 0]`인가요?

CIFAR-10의 정답 배열은 **세로 50,000행, 가로 1열**입니다. 예를 들어 다음과 같습니다.

```text
y_train = [[6],
           [9],
           [9],
           ...]

y_train[0]    → [6]  (원소가 하나인 배열)
y_train[0, 0] →  6   (정답 숫자 하나)
```

따라서 `int(y_train[i, 0])`로 **정답 숫자 하나**를 분명하게 꺼내면, NumPy 버전에 따라 배열을 정수로 변환할 때 생길 수 있는 경고도 피할 수 있습니다.

### ⑥ 사진을 변형하는 규칙 정하기

```python
batch_siz=4
generator=ImageDataGenerator(
    rotation_range=20.0,
    width_shift_range=0.2,
    height_shift_range=0.2,
    horizontal_flip=True
)
```

| 설정 | 아주 쉬운 의미 |
|---|---|
| `batch_siz=4` | 변형된 사진을 **한 번에 4장**씩 받습니다. |
| `rotation_range=20.0` | 사진을 최대 약 **±20도** 범위에서 회전합니다. |
| `width_shift_range=0.2` | 가로 길이의 약 **20% 범위**에서 좌우로 움직입니다. |
| `height_shift_range=0.2` | 세로 길이의 약 **20% 범위**에서 위아래로 움직입니다. |
| `horizontal_flip=True` | 사진을 **무작위로 좌우 반전**할 수 있습니다. |

사진이 기울어지거나 뒤집혀도 해당 사진의 **정답 이름은 그대로 유지**됩니다. 이 실습에서 수직 뒤집기는 사용하지 않습니다.

### ⑦ 증대 생성기 만들기

```python
gen=generator.flow(x_train,y_train,batch_size=batch_siz)
```

- `generator`: 사진을 바꾸는 **규칙**.
- `flow(...)`: 해당 규칙으로 사진과 정답을 계속 꺼낼 수 있는 **반복 가능한 생성기** 준비.
- `batch_size=4`: 호출할 때마다 **사진 4장과 정답 4개**를 받습니다.

사진을 전부 미리 저장하는 것이 아니라, 필요할 때 변형된 묶음을 만들어 가져옵니다.

### ⑧ 변형 사진을 가져오기 — 두 번째 핵심 수정

```python
for a in range(3):
    # img,label=gen.next()  # 현재 환경에서 지원되지 않아 변경
    img,label=next(gen)
```

`next(gen)`은 **생성기에서 다음 묶음을 하나 꺼내라**는 Python의 기본 함수입니다.

- 첫 번째 반복: 변형 사진 4장
- 두 번째 반복: 변형 사진 4장
- 세 번째 반복: 변형 사진 4장

즉 화면에 **3묶음 × 4장 = 총 12개의 증대 이미지**가 표시됩니다. **원본 15장과 별도로** 보여 주는 12개이며, 반드시 서로 다른 원본 12장을 한 번씩 사용하는 것은 아닙니다.

**수정 전:** `gen.next()` — 설치된 TensorFlow/Keras 버전에서 `AttributeError`가 날 수 있습니다.  
**수정 후:** `next(gen)` — Python의 표준 반복자 접근 방식입니다.

### ⑨ 변형된 사진 4장씩 화면에 출력하기 — 세 번째 핵심 수정

```python
plt.figure(figsize=(8,2.4))
plt.suptitle('Generatior trial '+str(a+1))
for i in range(batch_siz):
    plt.subplot(1,batch_siz,i+1)
    plt.imshow(img[i])
    plt.xticks([]); plt.yticks([])
    plt.title(class_names[int(label[i, 0])])
plt.show()
```

`label`도 `(4,1)` 모양의 배열이므로 `label[i, 0]`으로 **사진 한 장의 정답 숫자**를 읽습니다. 위에서 `y_train[i, 0]`을 사용한 이유와 같습니다.

제목의 `Generatior`는 `Generator`의 오타입니다. 결과에 영향은 없지만 고쳐도 좋습니다.

## 6. 이번에 수정된 코드 비교

| 항목 | 기존 코드 | 수정한 코드 | 수정 이유 |
|---|---|---|---|
| 원본 사진 제목 | `int(y_train[i])` | `int(y_train[i, 0])` | 1개짜리 배열 대신 **스칼라 정수** 꺼내기 |
| 다음 묶음 가져오기 | `gen.next()` | `next(gen)` | **현재 Keras 버전과 호환** |
| 증대 사진 제목 | `int(label[i])` | `int(label[i, 0])` | 정답 배열의 **원소 한 개** 꺼내기 |

## 8. 오류가 발생하면? (원인 → 확인 방법 → 수정 코드)

### 오류 A. `'NumpyArrayIterator' object has no attribute 'next'`

- **원인:** 현재 라이브러리 버전에서 `.next()` 메서드가 지원되지 않습니다.
- **확인:** 오류 위치가 `img,label=gen.next()`인지 살펴봅니다.
- **수정:**

```python
img,label=next(gen)
```

### 오류 B. 배열을 정수로 바꿀 때 경고 발생

- **원인:** `int(y_train[i])` 또는 `int(label[i])`처럼 **배열 전체**를 숫자로 변환하려고 했습니다.
- **확인:** `print(y_train.shape)`를 실행하면 `(15, 1)`이 나옵니다.
- **수정:**

```python
plt.title(class_names[int(y_train[i, 0])])
plt.title(class_names[int(label[i, 0])])
```

### 오류 C. `ImageDataGenerator` import 오류

- **원인:** 설치된 TensorFlow/Keras 조합에서 기존 이미지 생성기 API가 제공되지 않을 수 있습니다.
- **확인:** `from tensorflow.keras.preprocessing.image import ImageDataGenerator` 줄에서 오류가 나는지 확인합니다.
- **수정 방향:** 교재 코드를 그대로 학습하려면 해당 API를 지원하는 TensorFlow/Keras 환경이 필요합니다. **최신 보충 내용:** 새로운 프로젝트에서는 `tf.keras.layers.RandomRotation`, `RandomTranslation`, `RandomFlip` 등을 고려할 수 있습니다. 이들 레이어를 사용하는 코드는 원본 실습과 작성 방식이 다릅니다.
