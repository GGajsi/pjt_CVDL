# 8-3.py — MNIST 고성능 CNN 학습 후 파일로 저장하기

> **대상:** 인공지능·컴퓨터 비전 입문 학생  
> **읽는 방법:** ① 목적 → ② 흐름 → ③ 핵심 코드 → ④ 결과 → ⑤ 실습 순서로 읽어 보세요.  
> **기준:** 첨부한 원본 파이썬 파일을 설명합니다. 원본이 자동으로 수정되는 것은 아닙니다.

**학습 목표:** CNN을 훈련한 뒤 모델을 저장해 다음 프로그램에서 재사용합니다.

## 프로그램 목적

8-1보다 합성곱 층을 여러 개 사용하는 MNIST CNN을 훈련하고 **`cnn_v2.h5` 파일**로 저장합니다. **8-4.py가 바로 이 파일을 사용합니다.**

## 전체 흐름

`숫자 사진 준비 → CNN 여러 층 설계 → 학습 100번 → 모델 저장 → 정확도 확인`

## 중요한 코드 읽기

### 입력 자료

```python
x_train=x_train.reshape(60000,28,28,1)
x_train=x_train.astype(np.float32)/255.0
```

- 손글씨 사진 한 장은 28×28 흑백입니다.
- 마지막 `1`은 흑백 이미지 채널 수입니다.

### CNN 구조

```python
cnn.add(Conv2D(32,(3,3),activation='relu',input_shape=(28,28,1)))
cnn.add(Conv2D(32,(3,3),activation='relu'))
cnn.add(MaxPooling2D(pool_size=(2,2)))
cnn.add(Dropout(0.25))
```

- 같은 사진에서 두 차례 특징을 추출합니다.
- 풀링으로 정보량을 줄이고, Dropout으로 과도한 암기를 완화합니다.
- 두 번째 묶음은 `Conv2D(64,...)` 층을 두 번 사용합니다.
- `Flatten → Dense(512) → Dropout(0.5) → Dense(10,softmax)`로 최종 숫자를 선택합니다.

### 모델 훈련 및 저장

```python
hist=cnn.fit(x_train,y_train,batch_size=128,epochs=100,
             validation_data=(x_test,y_test),verbose=2)
cnn.save('cnn_v2.h5')
```

- `fit`: 학습을 진행합니다.
- `save`: 배운 **층 구조와 가중치**를 디스크에 기록합니다.
- 저장 파일은 현재 작업 폴더에 생성됩니다. 파이썬 소스 파일과 무조건 같은 폴더는 아닙니다.

## 모델 저장이 중요한 이유

모델을 저장하지 않으면 손글씨 인식 프로그램을 실행할 때마다 다시 학습해야 합니다. 저장하면 학습은 한 번 하고, 이후에는 **읽어 와서 예측**할 수 있습니다.

## 실행 결과

콘솔에 마지막 정확도가 표시되고 `cnn_v2.h5`가 생성됩니다. 이 코드는 학습 그래프를 출력하지는 않습니다(`hist`에 기록은 남습니다).

## 실습 과제

1. `epochs=100`을 `epochs=3`으로 설정해 실행 흐름부터 확인하세요.
2. 저장 파일이 실제로 만들어졌는지 확인하세요.
3. 저장한 모델을 다시 불러오는 `tf.keras.models.load_model('cnn_v2.h5')`를 연습하세요.

## 주의 사항

- 원본은 테스트 세트를 학습 중 검증에도 사용합니다. 별도의 검증 세트가 바람직합니다.
- `.h5`는 사용 가능한 저장 방식이지만 최신 Keras에서는 `.keras` 형식도 권장됩니다. **8-4의 로드 파일명까지 함께 바꾸기 전에는 원본 파일명을 유지**하세요.
- GPU 없이 100번 학습하면 오래 걸릴 수 있습니다.

## 먼저 알아둘 단어

| 용어 | 아주 쉬운 뜻 |
|---|---|
| 데이터셋 | 컴퓨터가 공부하거나 시험 볼 때 사용하는 이미지와 정답 모음 |
| 학습(훈련) | 이미지와 정답을 반복해서 보면서 내부 숫자(가중치)를 조절하는 과정 |
| 에포크(epoch) | 준비한 학습 데이터를 처음부터 끝까지 한 바퀴 공부하는 횟수 |
| 배치(batch) | 한 번에 모델에 넣는 이미지 묶음 |
| 정확도(accuracy) | 정답을 맞힌 비율. 예: 100장 중 95장 성공 → 95% |
| 손실(loss) | 예측이 정답에서 얼마나 벗어났는지 나타내는 점수. 대체로 낮을수록 좋음 |
| CNN | 이미지 속 모양과 특징을 단계적으로 찾아내는 신경망 |
