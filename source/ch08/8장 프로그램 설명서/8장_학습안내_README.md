# 8장 CNN·전이 학습 프로그램 학습 안내

## 순서대로 실습하기

| 파일 | 무엇을 배우나요? | 사전에 필요한 것 |
|---|---|---|
| 8-1.py | MNIST 숫자에 CNN 적용 | TensorFlow, NumPy |
| 8-2.py | CIFAR-10 컬러 사진 CNN, 학습 그래프 | TensorFlow, Matplotlib |
| 8-3.py | MNIST CNN 학습, 모델 저장 | TensorFlow; 모델 파일 생성 |
| 8-4.py | 마우스 손글씨 숫자 5개 인식 | **8-3에서 만든 cnn_v2.h5**, OpenCV, Matplotlib, Windows winsound |
| 8-5.py | 사진 회전·이동·반전 데이터 증대 | TensorFlow의 ImageDataGenerator 지원 여부 확인 |
| 8-6.py | 사전 학습 ResNet50 이미지 분류 | **rabbit.jpg**, 최초 다운로드용 인터넷 |
| 8-7.py | DenseNet121로 견종 120종 학습 | **Stanford Dogs 폴더**, 충분한 컴퓨팅 자원 |
| 8-8.py | PyQt5 견종 인식 GUI | **8-7의 cnn_for_stanford_dogs.h5 및 dog_species_names.txt**, PyQt5 |

## 먼저 배우는 개념 연결

- **7장 MLP:** 이미지를 숫자 하나의 긴 줄로 펼쳐 분류했습니다.
- **8-1~8-3 CNN:** 이미지의 가로·세로 구조를 활용해 특징을 배웁니다.
- **8-4 프로그램 응용:** 학습한 모델을 저장하고 불러와 실제 손글씨에 적용합니다.
- **8-5 데이터 증대:** 사진의 모습을 변화시켜 학습 데이터의 다양성을 높입니다.
- **8-6 사전 학습:** 이미 학습된 큰 모델을 새 사진 예측에 사용합니다.
- **8-7~8-8 전이 학습 응용:** 준비된 모델을 다른 과제에 적용하고 GUI로 사용합니다.

## 권장 실습 시간에 따른 전략

1. **빠르게 확인하기:** 8-1(에포크 3~5) → 8-3(에포크 3~5) → 8-4
2. **CNN 학습 비교하기:** 8-1 → 8-2(에포크 3~5) → 8-5
3. **사전 학습 모델 체험:** 8-6
4. **장기 프로젝트:** 8-7 → 8-8 (데이터·GPU·시간 사전 확인)

## 원본 소스 주요 실행 주의점

- `8-5.py`: `gen.next()` 오류 시 `next(gen)` 사용; `flog`는 `frog` 오타입니다.
- `8-7.py`: 입력 정규화 방식이 DenseNet121 사전 학습용 `preprocess_input`과 다릅니다.
- `8-8.py`: OpenCV의 BGR 입력과 RGB 훈련 영상 간 색 순서가 다릅니다.
- `8-1~8-3.py`: 테스트 세트를 학습 도중 검증에도 사용하고 있으므로 엄밀한 최종 평가는 데이터 분리 개선이 필요합니다.
- 각 실행 시간과 정확도는 PC 사양, TensorFlow 버전, 데이터에 따라 다릅니다. 본 설명서는 **실행 확인 결과를 주장하지 않으며** 원본 소스를 분석한 문서입니다.
