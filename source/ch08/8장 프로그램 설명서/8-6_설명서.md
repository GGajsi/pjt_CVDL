# 8-6.py — 사전 학습된 ResNet50으로 토끼 사진 분류하기

> **대상:** 인공지능·컴퓨터 비전 입문 학생  
> **읽는 방법:** ① 목적 → ② 흐름 → ③ 핵심 코드 → ④ 결과 → ⑤ 실습 순서로 읽어 보세요.  
> **기준:** 첨부한 원본 파이썬 파일을 설명합니다. 원본이 자동으로 수정되는 것은 아닙니다.

**학습 목표:** 이미 큰 데이터로 학습된 AI를 가져와 별도 훈련 없이 사진을 분류합니다.

## 이 프로그램이 하는 일

`rabbit.jpg` 파일을 읽고, **ImageNet으로 미리 학습된 ResNet50**에게 어떤 사진인지 맞혀 보라고 요청합니다. 상위 **5개** 후보와 점수를 콘솔과 이미지에 표시합니다.

## 실행 흐름

`ResNet50 가져오기 → rabbit.jpg 읽기 → 224×224로 크기 맞추기 → 전용 전처리 → 예측 → 상위 5개 출력`

## 중요한 코드

### 준비된 AI 모델 불러오기

```python
model=ResNet50(weights='imagenet')
```

- `ResNet50`: 이미지 분류용으로 널리 알려진 CNN 구조입니다.
- `weights='imagenet'`: ImageNet 데이터로 미리 학습한 가중치를 불러옵니다.
- 처음 실행할 때는 모델 파일을 다운로드할 수 있어 인터넷이 필요할 수 있습니다.

### 사진을 모델에 맞게 바꾸기

```python
img=cv.imread('rabbit.jpg')
x=np.reshape(cv.resize(img,(224,224)),(1,224,224,3))
x=preprocess_input(x)
```

- `cv.imread`: 파일에서 사진을 읽습니다.
- `224×224`: ResNet50 입력 크기에 맞춥니다.
- `(1,224,224,3)`의 `1`은 사진 **한 장**, `3`은 색상 채널입니다.
- `preprocess_input`: ResNet50이 학습할 때 사용한 규칙에 맞춰 픽셀 값을 바꿉니다. **단순히 255로 나누는 작업과 다릅니다.**
- 이 소스는 OpenCV의 **BGR** 이미지와 Keras ResNet50의 전처리 방식이 맞물리는 구성입니다.

### 상위 5개 정답 후보 얻기

```python
preds=model.predict(x)
top5=decode_predictions(preds,top=5)[0]
```

- `predict`는 이미지 분류 점수를 계산합니다.
- `decode_predictions`는 숫자 인덱스를 사람이 읽는 영문 라벨로 바꿉니다.
- `top=5`는 점수가 높은 5개의 후보를 의미합니다. 이 후보가 모두 정답이라는 뜻은 아닙니다.

### 사진에 글씨 쓰기

```python
cv.putText(img,top5[i][1]+':'+str(top5[i][2]), ...)
```

이미지 위에 **후보 이름과 점수**를 적습니다. `cv.imshow`로 사진을 보여 주고 키를 누르면 창을 닫습니다.

## 실행 전에 확인

- `rabbit.jpg`가 **현재 작업 폴더**에 있어야 합니다.
- 파일을 읽지 못하면 `cv.resize`에서 오류가 발생할 수 있습니다. `if img is None: ...` 검사 추가를 권장합니다.
- ResNet50이 이미 학습했기 때문에 이 소스에는 `fit()`이 없습니다.

## 먼저 알아둘 단어

| 용어 | 아주 쉬운 뜻 |
|---|---|
| 데이터셋 | 컴퓨터가 공부하거나 시험 볼 때 사용하는 이미지와 정답 모음 |
| 학습(훈련) | 이미지와 정답을 반복해서 보면서 내부 숫자(가중치)를 조절하는 과정 |
| 에포크(epoch) | 준비한 학습 데이터를 처음부터 끝까지 한 바퀴 공부하는 횟수 |
| 배치(batch) | 한 번에 모델에 넣는 이미지 묶음 |
| 정확도(accuracy) | 정답을 맞힌 비율. 예: 100장 중 95장 성공 → 95% |
| 손실(loss) | 예측이 정답에서 얼마나 벗어났는지 나타내는 점수. 대체로 낮을수록 좋음 |
| CNN | 이미지 속 모양과 특징을 단계적으로 찾아내는 신경망 |
