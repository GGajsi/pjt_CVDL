# 8-4.py — 마우스로 쓴 숫자 5개를 CNN이 읽어 주기

> **대상:** 인공지능·컴퓨터 비전 입문 학생  
> **읽는 방법:** ① 목적 → ② 흐름 → ③ 핵심 코드 → ④ 결과 → ⑤ 실습 순서로 읽어 보세요.  
> **기준:** 첨부한 원본 파이썬 파일을 설명합니다. 원본이 자동으로 수정되는 것은 아닙니다.

**학습 목표:** 그림판처럼 숫자를 직접 쓰면 저장된 CNN 모델이 예측합니다.

## 프로그램에서 해 볼 일

흰색 창의 **빨간색 칸 5개**에 마우스로 숫자를 적고 `r` 키를 누르면, 각 칸의 숫자를 인식해 아래에 표시합니다.

> **먼저 실행:** `8-3.py`를 실행하여 `cnn_v2.h5` 모델 파일을 만들어야 합니다.

## 사용 방법

| 조작 | 동작 |
|---|---|
| 마우스 왼쪽 버튼 누르고 이동 | 검은색 글씨 쓰기 |
| `s` | 모델에 넣기 전의 28×28 사진 5장 보기 |
| `r` | 숫자 5개 인식하기 |
| `e` | 화면 지우고 다시 시작 |
| `q` | 프로그램 종료 |

## 코드 흐름

`저장된 모델 열기 → 그리기 창 표시 → 마우스로 입력 → 5칸 자르기 → 28×28로 축소 → 예측 → 숫자 표시`

## 코드의 핵심을 이해해 봅시다

### 훈련한 모델 읽기

```python
model=tf.keras.models.load_model('cnn_v2.h5')
```

이미 학습한 모델을 읽습니다. 새로 학습하는 코드는 없습니다.

### 흰색 캔버스 5칸

```python
img=np.ones((200,520,3),dtype=np.uint8)*255
for i in range(5):
    cv.rectangle(img,(10+i*100,50),(10+(i+1)*100,150),(0,0,255))
```

- `np.ones(...)*255`는 흰색 화면을 만듭니다.
- `for` 반복문으로 사각형을 **100픽셀 간격**으로 5개 그립니다.

### 손글씨 잘라내기

```python
roi=img[51:149,11+i*100:9+(i+1)*100,0]
roi=255-cv.resize(roi,(28,28),interpolation=cv.INTER_CUBIC)
```

- `roi`는 각 숫자가 들어 있는 사각형 **안쪽 영역**입니다.
- 원본 창의 **흰 배경/검은 글씨**를 모델이 학습한 MNIST에 가깝도록 **검은 배경/밝은 글씨**로 뒤집습니다.
- `resize`는 사진을 28×28로 줄입니다.

### CNN에 맞는 형태로 변환

```python
numerals=numerals.reshape(5,28,28,1)
numerals=numerals.astype(np.float32)/255.0
res=model.predict(numerals)
class_id=np.argmax(res,axis=1)
```

- `(5,28,28,1)`은 **숫자 사진 5장 × 28×28 × 흑백 1채널**입니다.
- 각 사진의 점수를 계산한 뒤, `argmax`가 가장 높은 점수의 숫자를 골라줍니다.

### 마우스와 키보드 처리

- `cv.setMouseCallback('Writing',writing)`은 마우스 동작이 있을 때 `writing()`을 실행하도록 연결합니다.
- `cv.waitKey(1)`은 키보드 입력을 읽고 화면을 계속 갱신합니다.
- `winsound.Beep(1000,500)`은 인식 후 소리를 냅니다. Windows 전용입니다.

## 실행 주의 사항

- `cnn_v2.h5`가 **현재 작업 폴더**에 없으면 시작할 때 오류가 발생합니다.
- `r` 키를 여러 번 누르면 예측 숫자가 기존 화면에 덧써집니다. `e`로 지우고 다시 시도하세요.
- 숫자가 칸에 너무 작거나 한쪽으로 치우치면 인식이 잘 안 될 수 있습니다.
- 원본은 **각 칸을 직접 축소**하므로 MNIST처럼 가운데 정렬·획 두께 보정은 하지 않습니다.

## 먼저 알아둘 단어

| 용어 | 아주 쉬운 뜻 |
|---|---|
| 데이터셋 | 컴퓨터가 공부하거나 시험 볼 때 사용하는 이미지와 정답 모음 |
| 학습(훈련) | 이미지와 정답을 반복해서 보면서 내부 숫자(가중치)를 조절하는 과정 |
| 에포크(epoch) | 준비한 학습 데이터를 처음부터 끝까지 한 바퀴 공부하는 횟수 |
| 배치(batch) | 한 번에 모델에 넣는 이미지 묶음 |
| 정확도(accuracy) | 정답을 맞힌 비율. 예: 100장 중 95장 성공 → 95% |
| 손실(loss) | 예측이 정답에서 얼마나 벗어났는지 나타내는 점수. 대체로 낮을수록 좋음 |
| CNN | 이미지 속 모양과 특징을 단계적으로 찾아내는 신경망 |
