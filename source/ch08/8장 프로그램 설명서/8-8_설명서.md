# 8-8.py — 사진을 선택하면 강아지 품종 상위 5개 알려 주기

> **대상:** 인공지능·컴퓨터 비전 입문 학생  
> **읽는 방법:** ① 목적 → ② 흐름 → ③ 핵심 코드 → ④ 결과 → ⑤ 실습 순서로 읽어 보세요.  
> **기준:** 첨부한 원본 파이썬 파일을 설명합니다. 원본이 자동으로 수정되는 것은 아닙니다.

**학습 목표:** 8-7에서 훈련한 모델로 사진을 읽어 강아지의 품종 후보를 표시합니다.

## 무엇을 만들까요?

버튼이 달린 작은 창에서 강아지 사진을 선택한 뒤 **`품종 인식`**을 누르면, 사진 위에 예측 점수가 높은 **상위 5개 품종**을 표시합니다.

> **필수 준비물:** 8-7 실행으로 생성된 `cnn_for_stanford_dogs.h5`와 `dog_species_names.txt` 두 파일이 **현재 작업 폴더**에 필요합니다.

## 사용 순서

1. `강아지 사진 열기` 버튼을 누릅니다.
2. JPG 등 강아지 사진 파일을 선택합니다.
3. `품종 인식` 버튼을 누릅니다.
4. 사진 위에 나타난 품종 후보 5개를 살펴봅니다.
5. `나가기` 버튼을 누르면 종료됩니다.

## 코드 쉽게 풀이

### 모델과 이름표 읽기

```python
cnn=tf.keras.models.load_model('cnn_for_stanford_dogs.h5')
dog_species=pickle.load(open('dog_species_names.txt','rb'))
```

- 첫 줄: 훈련한 CNN 모델을 불러옵니다.
- 둘째 줄: 0번, 1번, ... 같은 **품종 번호가 실제 어떤 품종인지** 알아낼 이름표를 읽습니다.
- `pickle`은 파이썬 데이터를 저장·복원하는 형식입니다. **신뢰할 수 없는 pickle 파일은 열지 마세요.**

### 창과 버튼 만들기

```python
class DogSpeciesRecognition(QMainWindow):
    ...
    fileButton.clicked.connect(self.pictureOpenFunction)
    recognitionButton.clicked.connect(self.recognitionFunction)
```

- `QMainWindow`: 윈도우 프로그램의 기본 화면을 만듭니다.
- `QPushButton`: 누를 수 있는 버튼을 만듭니다.
- `.clicked.connect(...)`: 버튼을 클릭하면 어떤 함수를 실행할지 연결합니다.

### 사진 열기

```python
fname=QFileDialog.getOpenFileName(self,'강아지 사진 읽기','./')
self.img=cv.imread(fname[0])
cv.imshow('Dog image',self.img)
```

파일 선택 창에서 경로를 골라 OpenCV로 사진을 읽고 표시합니다. **파일 선택을 취소했을 때** 원본은 `sys.exit(...)`로 프로그램을 종료할 수 있어 사용성 개선이 필요합니다.

### 품종 상위 5개 예측

```python
x=np.reshape(cv.resize(self.img,(224,224)),(1,224,224,3))
res=cnn.predict(x)[0]
top5=np.argsort(-res)[:5]
```

- 모델이 요구하는 크기 **224×224**로 조절합니다.
- `(1,224,224,3)`은 컬러 사진 한 장입니다.
- `predict`는 120개 품종의 점수를 계산합니다.
- `np.argsort(-res)[:5]`는 점수가 높은 품종의 **번호 상위 5개**를 구합니다.
- 그 번호로 품종 이름을 찾고, `cv.putText`로 화면에 표시합니다.

## 매우 중요한 정확도 주의 사항

- **원본 8-7은 학습할 때 `Rescaling(1/255)`을 적용합니다.** 그런데 8-8에는 별도의 `/255` 코드가 없습니다. 저장된 8-7 모델의 `Rescaling` 층이 그대로 들어 있다면 이 자체는 중복 없이 동작합니다.
- 단, 8-7 학습 이미지는 일반적으로 **RGB**, `cv.imread`로 읽은 8-8 이미지는 **BGR**입니다. 원본 8-8은 RGB로 바꾸지 않으므로, 색 순서가 달라 예측 품질이 저하될 수 있습니다. 필요하면 `cv.cvtColor(self.img,cv.COLOR_BGR2RGB)` 후 리사이즈하는 방식으로 맞추세요. (원본에는 없는 개선 사항)
- `str(...).split('-')[1]`은 품종 폴더 이름에 `-`가 없으면 오류가 날 수 있습니다. 실제 폴더 이름 형식을 확인하세요.
- `self.img`가 없는 상태에서 먼저 **품종 인식**을 누르면 오류가 발생합니다. 파일을 먼저 선택해야 합니다.
- `cv.putText`가 원본 사진 `self.img`를 직접 변경하기 때문에 다시 인식하면 글씨가 중첩됩니다.

## 먼저 알아둘 단어

| 용어 | 아주 쉬운 뜻 |
|---|---|
| 데이터셋 | 컴퓨터가 공부하거나 시험 볼 때 사용하는 이미지와 정답 모음 |
| 학습(훈련) | 이미지와 정답을 반복해서 보면서 내부 숫자(가중치)를 조절하는 과정 |
| 에포크(epoch) | 준비한 학습 데이터를 처음부터 끝까지 한 바퀴 공부하는 횟수 |
| 배치(batch) | 한 번에 모델에 넣는 이미지 묶음 |
| 정확도(accuracy) | 정답을 맞힌 비율. 예: 100장 중 95장 성공 → 95% |
| 손실(loss) | 예측이 정답에서 얼마나 벗어났는지 나타내는 점수. 대체로 낮을수록 좋음 |
| CNN | 이미지 속 모양과 특징을 단계적으로 찾아내는 신경망 |
