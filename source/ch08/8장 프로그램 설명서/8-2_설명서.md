# 8-2.py — CIFAR-10 컬러 사진을 CNN으로 분류하기

> **대상:** 인공지능·컴퓨터 비전 입문 학생  
> **읽는 방법:** ① 목적 → ② 흐름 → ③ 핵심 코드 → ④ 결과 → ⑤ 실습 순서로 읽어 보세요.  
> **기준:** 첨부한 원본 파이썬 파일을 설명합니다. 원본이 자동으로 수정되는 것은 아닙니다.

**학습 목표:** 색깔 사진 속 비행기·고양이·자동차 등 10개 종류를 구분합니다.

## 프로그램 한눈에 보기

- **입력:** CIFAR-10 컬러 사진 32×32×3, 학습 50,000장 / 테스트 10,000장
- **출력:** 테스트 정확도와 학습/검증 정확도·손실 그래프
- **핵심:** CNN, MaxPooling, Dropout, 학습 곡선

## 실행 흐름

`CIFAR-10 불러오기 → 픽셀 0~1 정규화 → 정답 10칸으로 변환 → CNN 학습(100 epochs) → 정확도 출력 → 두 그래프 표시`

## 핵심 코드 쉽게 이해하기

### 사진 준비

```python
(x_train,y_train),(x_test,y_test)=ds.cifar10.load_data()
x_train=x_train.astype(np.float32)/255.0
y_train=tf.keras.utils.to_categorical(y_train,10)
```

- 사진 한 장은 **가로 32×세로 32, RGB 색상 채널 3개**입니다.
- 이번에는 8-1과 달리 `reshape`가 필요 없습니다. 처음부터 CNN이 받을 수 있는 컬러 사진 모양이기 때문입니다.

### 작은 모양부터 차례로 찾기

```python
cnn.add(Conv2D(32,(3,3),activation='relu',input_shape=(32,32,3)))
cnn.add(Conv2D(32,(3,3),activation='relu'))
cnn.add(MaxPooling2D(pool_size=(2,2)))
cnn.add(Dropout(0.25))
```

- `Conv2D`: 사진에서 선, 질감 같은 단서를 찾습니다.
- `32`: 특징 지도를 32개 만듭니다. 사진 32장을 만든다는 뜻은 아닙니다.
- `MaxPooling2D`: 가장 강한 특징을 남기고 크기를 줄입니다.
- `Dropout(0.25)`: **훈련 중** 뉴런 출력의 약 25%를 임시로 꺼서 특정 패턴만 외우는 것을 줄입니다.
- 다음에는 필터 64개짜리 합성곱 층 2개와 풀링·Dropout을 반복합니다.

### 판단을 내리는 층

```python
cnn.add(Flatten())
cnn.add(Dense(units=512,activation='relu'))
cnn.add(Dropout(0.5))
cnn.add(Dense(units=10,activation='softmax'))
```

- `Flatten`은 추출한 특징을 일렬로 폅니다.
- `Dense(512)`는 특징을 종합합니다.
- `Dropout(0.5)`는 학습 중 출력의 절반 정도를 임시로 끕니다.
- 마지막 10칸은 CIFAR-10의 10개 종류에 대한 예측 점수입니다.

### 학습 그래프 읽기

```python
hist=cnn.fit(x_train,y_train,batch_size=128,epochs=100,
             validation_data=(x_test,y_test),verbose=2)
plt.plot(hist.history['accuracy'])
plt.plot(hist.history['val_accuracy'])
```

- `accuracy`: 학습용 사진을 얼마나 잘 맞혔는지
- `val_accuracy`: 학습 중 평가용 사진을 얼마나 잘 맞혔는지
- 두 선의 차이가 크게 벌어지면 **과적합**을 의심할 수 있습니다.
- `loss`와 `val_loss`는 오답 정도가 줄어드는지도 보여 줍니다.

## 실행할 때 기억하세요

- `epochs=100`은 CPU 환경에서 오래 걸릴 수 있습니다. 첫 실행은 **3~5 epoch**로 확인해도 됩니다.
- 코드가 테스트 세트를 검증에도 사용합니다. 학습 설계 개선 시 훈련 데이터에서 검증 세트를 따로 분리하세요.
- 그래프 선의 값은 실행할 때마다 같다고 보장할 수 없습니다.

## 먼저 알아둘 단어

| 용어 | 아주 쉬운 뜻 |
|---|---|
| 데이터셋 | 컴퓨터가 공부하거나 시험 볼 때 사용하는 이미지와 정답 모음 |
| 학습(훈련) | 이미지와 정답을 반복해서 보면서 내부 숫자(가중치)를 조절하는 과정 |
| 에포크(epoch) | 준비한 학습 데이터를 처음부터 끝까지 한 바퀴 공부하는 횟수 |
| 배치(batch) | 한 번에 모델에 넣는 이미지 묶음 |
| 정확도(accuracy) | 정답을 맞힌 비율. 예: 100장 중 95장 성공 → 95% |
| 손실(loss) | 예측이 정답에서 얼마나 벗어났는지 나타내는 점수. 대체로 낮을수록 좋음 |
| CNN | 이미지 속 모양과 특징을 단계적으로 찾아내는 신경망 |
