# 8-7.py — DenseNet121로 강아지 품종 120종 학습하기

> **대상:** 인공지능·컴퓨터 비전 입문 학생  
> **읽는 방법:** ① 목적 → ② 흐름 → ③ 핵심 코드 → ④ 결과 → ⑤ 실습 순서로 읽어 보세요.  
> **기준:** 첨부한 원본 파이썬 파일을 설명합니다. 원본이 자동으로 수정되는 것은 아닙니다.

**학습 목표:** 기존 사전 학습 CNN을 강아지 품종 분류 문제에 맞게 추가 학습합니다.

## 이 프로그램의 목표

Stanford Dogs 이미지 폴더를 읽고, ImageNet으로 미리 학습된 **DenseNet121**을 사용해 **강아지 품종 120종**을 구분하도록 훈련합니다. 학습한 모델과 품종 이름 목록을 저장합니다.

> 이 예제는 8장 중 **실행 준비와 컴퓨팅 자원이 가장 많이 필요한 편**입니다. 코드에 `epochs=200`, 이미지 크기 224×224, 배치 16이 설정되어 있습니다.

## 전체 작업 흐름

`강아지 사진 폴더 준비 → 80%/20% 분리 → DenseNet121 준비 → 분류층 추가 → 학습 → 정확도 확인 → 모델과 품종 이름 저장 → 그래프 보기`

## 코드 해설

### 사진 폴더를 데이터셋으로 만들기

```python
data_path=pathlib.Path('datasets/stanford_dogs/images/images')
train_ds=image_dataset_from_directory(
    data_path,validation_split=0.2,subset='training',
    seed=123,image_size=(224,224),batch_size=16)
```

- 경로 밑에는 **품종별로 나뉜 하위 폴더**가 있어야 합니다.
- 폴더 이름을 사용해 정답 라벨을 자동으로 붙입니다.
- `validation_split=0.2`: 사진의 약 **80%는 학습**, 약 **20%는 검증**에 사용합니다.
- 두 번 호출할 때 같은 `seed=123`을 사용해 학습/검증 구성을 일관되게 만듭니다.
- 소스의 `test_ds`라는 이름은 실제로는 **validation 분할**입니다. 별도의 최종 테스트셋은 아닙니다.

### 이미 배운 DenseNet121 재활용

```python
base_model=DenseNet121(weights='imagenet',include_top=False,
                       input_shape=(224,224,3))
cnn.add(Rescaling(1.0/255.0))
cnn.add(base_model)
```

- `weights='imagenet'`: 다른 이미지로 배운 특징 추출 능력을 가져옵니다.
- `include_top=False`: 기존 ImageNet 분류의 마지막 머리 부분은 제외합니다.
- `Rescaling(1.0/255.0)`: 픽셀 밝기를 0~1 범위로 조정합니다.
- **매우 중요한 실습 주의:** DenseNet121의 공식 사전 학습 가중치와 맞추려면 일반적으로 `tf.keras.applications.densenet.preprocess_input`을 사용해야 합니다. 원본의 단순 `Rescaling(1/255)`은 사전 학습 때와 입력 분포가 달라 성능에 영향을 줄 수 있습니다.

### 강아지 품종용 새 분류기

```python
cnn.add(Flatten())
cnn.add(Dense(1024,activation='relu'))
cnn.add(Dropout(0.75))
cnn.add(Dense(units=120,activation='softmax'))
```

- `Flatten`: 특징 지도를 긴 숫자 줄로 폅니다.
- `Dense(1024)`: 품종 구별에 필요한 조합을 학습합니다.
- `Dropout(0.75)`: 훈련 시 출력을 많이 끄는 **강한 규제**입니다.
- `Dense(120)`: 120개 품종 각각에 대한 점수를 출력합니다. 실제 폴더 클래스도 120개인지 확인해야 합니다.

### 공부시키고 결과 저장

```python
cnn.compile(loss='sparse_categorical_crossentropy',
            optimizer=Adam(learning_rate=0.000001),metrics=['accuracy'])
hist=cnn.fit(train_ds,epochs=200,validation_data=test_ds,verbose=2)
cnn.save('cnn_for_stanford_dogs.h5')
```

- `sparse_categorical_crossentropy`는 정답이 `0,1,2...`처럼 **정수 번호**일 때 사용하는 분류 손실입니다.
- `learning_rate=0.000001`: 아주 작은 학습률로 미세하게 조정합니다.
- `base_model.trainable=False`가 없으므로 **DenseNet121 내부까지 학습될 수 있습니다**. 즉, 고정된 특징 추출만 하는 방식이 아닙니다.
- `pickle.dump(train_ds.class_names,...)`는 품종 이름 목록을 `dog_species_names.txt`에 **바이너리 형태로 저장**합니다. 확장자가 `.txt`여도 일반 텍스트가 아닙니다.

## 학습 중 그래프 해석

- `accuracy`: 학습 사진에 대한 정답률
- `val_accuracy`: 검증 사진에 대한 정답률
- `loss`/`val_loss`: 학습·검증 오차의 흐름
- 학습 정확도만 올라가고 검증 정확도가 떨어지면 과적합 가능성이 있습니다.

## 실현 가능한 실습 순서

1. 먼저 **데이터 폴더 구조와 클래스 수 120개**를 확인하세요.
2. 처음에는 `epochs=1`로 코드가 동작하는지 시험하세요.
3. CPU 환경에서 전체 DenseNet121을 200회 학습시키는 것은 매우 부담스러울 수 있습니다. GPU 환경과 데이터 규모를 확인하세요.
4. 실제 프로젝트에서는 DenseNet 일부 또는 전체를 먼저 `trainable=False`로 고정해 분류층만 학습시키고, 필요하면 일부를 풀어 미세 조정하는 방법을 검토하세요. 이는 **원본에 없는 개선 제안**입니다.

## 원본에서 주의할 점

- 모델의 입력 전처리 방식과 DenseNet 사전 학습 전처리 방식이 다릅니다.
- `Flatten` + `Dense(1024)` 때문에 파라미터가 커질 수 있습니다. `GlobalAveragePooling2D`는 대안이지만 원본에는 없습니다.
- 200 epoch와 초소형 학습률은 많은 시간이 필요할 수 있으며, 목표 정확도는 보장되지 않습니다.
- 학습에 사용한 `test_ds`는 정확히는 검증용 데이터입니다.

## 먼저 알아둘 단어

| 용어 | 아주 쉬운 뜻 |
|---|---|
| 데이터셋 | 컴퓨터가 공부하거나 시험 볼 때 사용하는 이미지와 정답 모음 |
| 학습(훈련) | 이미지와 정답을 반복해서 보면서 내부 숫자(가중치)를 조절하는 과정 |
| 에포크(epoch) | 준비한 학습 데이터를 처음부터 끝까지 한 바퀴 공부하는 횟수 |
| 배치(batch) | 한 번에 모델에 넣는 이미지 묶음 |
| 정확도(accuracy) | 정답을 맞힌 비율. 예: 100장 중 95장 성공 → 95% |
| 손실(loss) | 예측이 정답에서 얼마나 벗어났는지 나타내는 점수. 대체로 낮을수록 좋음 |
| CNN | 이미지 속 모양과 특징을 단계적으로 찾아내는 신경망 |
